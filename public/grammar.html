rule literal or token choice optional repeat

Parser Overview

NEWLINE* → header-document | score-document → EOF

The parser chooses header-document if any = token appears ahead in the file. Otherwise the same input is parsed as score-only notation. 

document        ::= NEWLINE* (header_document | score_document) EOF
header_document ::= header NEWLINE* score?
score_document  ::= score?

Header

(NEWLINE | header-property)* → EQUALS+ → NEWLINE+
IDENTIFIER → : → STRING → NEWLINE | before EQUALS 
header          ::= (NEWLINE | header_property)* EQUALS+ NEWLINE+
header_property ::= IDENTIFIER ":" STRING (NEWLINE | before EQUALS)

Semantic header fields are title, subtitle, composer, key, time, tempo, and hidden. Unknown fields are preserved in header.raw.

Score

(NEWLINE | line)* 
score ::= (NEWLINE | line)*

Line

label? → leading BAR? → measure → (BAR measure)* → trailing BAR? 
line  ::= label? BAR? measure (BAR measure)* BAR?
label ::= IDENTIFIER ":"

A single leading bar and a single trailing bar are accepted. Empty measures are still parse errors; for example, 1 2 || 3 4 creates an empty measure between the two bar tokens.

Measure

measure-octave? → durable-note+ 
measure        ::= measure_octave? durable_note+
measure_octave ::= LOWER+ | HIGHER+

A measure octave prefix is consumed only at the start of the measure. It is one repeated token kind: ,+ or '+. Mixed prefixes are not one prefix.

Durable Note

TIE? → general-note → duration? 
durable_note ::= TIE? general_note duration?

Tie legality is validated after parsing. A leading ~ is syntactically accepted here, then rejected later if it is the first note, follows a rest, or does not match the previous sounding note.

General Note

pitch | rest | drum | chord 
general_note ::= pitch | REST | DRUM | chord

Pitch

accidental? → NOTE → octave-suffix? 
pitch         ::= accidental? NOTE octave_suffix?
accidental    ::= SHARPSHARP | SHARP | FLATFLAT | FLAT | NATURAL
octave_suffix ::= LOWER+ | HIGHER+

Chord

{ → pitch+ → } 
chord ::= "{" pitch+ "}"

Chords contain pitch notes only. Rests, drum notes, duration suffixes before }, and empty chords are invalid.

Duration

DASH+ | (HALF | DOT)+ 
duration ::= DASH+ | (HALF | DOT)+

Dash duration marks cannot be combined with slash or dot marks. The parser reports a specific duration error for forms such as 1-/ and 1/-.

Tokenizer

space | tab | comment → skipped 
IDENTIFIER ::= /[A-Za-z_]+/ except bb, b, X
STRING     ::= '"' (escaped-char | non-newline-non-quote)* '"'
NOTE       ::= "1" | "2" | "3" | "4" | "5" | "6" | "7"
REST       ::= "0"
DRUM       ::= "X"
BAR        ::= "|"
SHARPSHARP ::= "##"
SHARP      ::= "#"
FLATFLAT   ::= "bb"
FLAT       ::= "b"
NATURAL    ::= "%"
HALF       ::= "/"
DOT        ::= "."
DASH       ::= "-"
LOWER      ::= ","
HIGHER     ::= "'"
TIE        ::= "~"
EQUALS     ::= "="
NEWLINE    ::= "\n" | "\r\n" | "\r"
COMMENT    ::= ";" characters-until-newline

Semantic Checks Not Shown As Syntax

  • Header key, time, and tempo values are normalized and validated after raw header parsing.
  • Measure durations are compared with the time signature after parsing and reported as warnings.
  • Ties are validated after parsing, using measure-local accidental persistence.
  • Accidentals persist within a measure for playback and tie validation, then reset at measure boundaries.
