## Document Structure

A `.jpu` file has optional leading blank lines, an optional header, optional score text, and then end of file.

```ebnf
file = { NEWLINE }, [ header ], [ score ], EOF ;
header = { property }, EQUALS, { EQUALS }, NEWLINE, { NEWLINE } ;
score = score_item, { NEWLINE, { NEWLINE }, score_item }, { NEWLINE } ;
score_item = line | lyric_line ;
```

A header is recognized only when a separator line is present. The separator is one or more `=` characters on its own line. Without the separator, the whole file is score text. Empty files are valid and use the default header values.

Spaces and tabs may appear between score tokens. Comments begin with `;` and continue to the next line break. Line breaks separate header fields, score lines, and lyric lines; consecutive blank lines are treated as one separator.

## Header

Header fields use `name: "value"` and must appear before the separator. Names start with an ASCII letter and may continue with ASCII letters, digits, or underscores. Unknown fields are preserved as metadata but have no built-in effect.

| Field | Default | Meaning |
| --- | --- | --- |
| `title` | empty | Main title rendered above the score. |
| `subtitle` | empty | Secondary title text. |
| `composer` | empty | Composer or source text. |
| `key` | `C` | Key signature for rendering, playback, and export. |
| `time` | `4/4` | Time signature used for measure-duration validation and export metadata. |
| `tempo` | `120` | Beats per minute for playback and export. |
| `hidden` | empty | Any non-empty value hides the rendered header block. |

Track and lyric display-name fields can also be written in the header, for example `T1: "Melody"` and `L1: "Verse"`.

Strings are double quoted and must stay on one line. A backslash skips the following character during tokenization, but the backslash is preserved as source text rather than interpreted as an escape sequence.

Supported `key` values are `C`, `C#`, `Db`, `D`, `D#`, `Eb`, `E`, `F`, `F#`, `Gb`, `G`, `G#`, `Ab`, `A`, `A#`, `Bb`, and `B`. One space inside the value is ignored. Accidental-first spellings such as `#C` and `bB` are also accepted.

Allowed `time` numerators are `2`, `3`, `4`, `6`, `9`, and `12`. Allowed denominators are `2`, `4`, `8`, and `16`.

`tempo` must be a positive number. Integer and decimal values are accepted.

## Music Tokens

| Construct | Syntax |
| --- | --- |
| Pitch note | `1` through `7` |
| Rest | `0` |
| Drum note | `X` |
| Accidentals | `#`, `##`, `b`, `bb`, `%` |
| Octave suffix | `1'`, `1''`, `1,`, `1,,` |
| Measure octave prefix | `' 1 2 3`, `, 1 2 3` |
| Chord | `{1 3 5}` |
| Tie | `~1` |
| Comment | `; comment` |

Accidentals apply only to pitch notes. They persist within a measure for playback, export, and tie validation, then reset at the next measure boundary.

Octave suffixes follow a pitch note. A measure-level octave prefix appears before any notes in the measure and applies to all pitch notes in that measure; per-note suffixes add to it.

Chords contain pitch notes only. Rests, drum notes, and duration suffixes before `}` are invalid. Empty chords are accepted, rendered as rests, and reported as warnings.

A tie marker appears before the tied note. A tied note must follow a compatible sounding note in the same track; ties after rests, first-note ties, and pitch-changing ties are errors. Drum notes can tie to previous drum notes.

## Durations

The default duration is a quarter note. Duration suffixes follow a note, rest, drum note, or chord.

| Syntax | Duration |
| --- | --- |
| `1` | quarter note |
| `1-` | half note |
| `1--` | dotted half note |
| `1---` | whole note |
| `1/` | eighth note |
| `1//` | sixteenth note |
| `1///` | thirty-second note |
| `1.` | dotted quarter note |
| `1..` | double-dotted quarter note |
| `1/.` | dotted eighth note |

Dash durations cannot be combined with slash or dot durations. Stray duration marks, such as `/1`, `.1`, or `-1`, are errors.

## Score Layout

```ebnf
line = [ track_label ], [ start_barline ], [ ending ], [ measure ],
  { measure_separator, [ ending ], [ measure ] }, [ end_barline ] ;
lyric_line = [ lyric_label ], STRING ;
```

| Construct | Syntax |
| --- | --- |
| Measure separator | `\|` |
| Repeat start | `\|:` |
| Repeat end | `:\|` |
| Repeat end/start | `:\|:` |
| Repeated ending | `[1]`, `[2]`, `[1,3]` |
| Track label | `T1:` through `T9:`, `T11:` through `T16:` |
| Lyric line | `L1: "lyrics"` or `"lyrics"` |

A line may start with a single barline or repeat start. A line may end with a single barline or repeat end. Consecutive bar tokens create an empty-measure warning, and the empty measure is ignored.

Repeated endings use bracket markers. Non-final endings return with `:|`; the final ending is explicit and does not use `:|`. When more measures follow a final ending marker, only the first measure after that marker is treated as part of the ending.

`T10:` is reserved for MIDI drums and is not accepted as a score-line label. If any score line has a track label, score lines are divided into groups. Each group starts at `T1` and increases by track number; examples such as `T1 T2 T3 T1 T2` and `T1 T1 T2` are valid.

Lyrics follow the score line or voice group they annotate. An unlabeled quoted lyric line is treated as `L1`. Lyrics do not affect playback or export timing. If whitespace-separated syllables match the main voice note count and the main voice fits on one rendered row, syllables are centered under sounding notes; rests are skipped.

## Diagnostics Summary

Warnings keep the document usable. Current warnings include measure-duration mismatches, empty measures, empty chords, and lyric syllable-count mismatches.

Errors prevent a valid parsed score. Common errors include malformed header fields, missing header separator when header mode is detected, unterminated strings, invalid key/time/tempo values, unexpected characters, invalid chord members, unmatched chord braces, mixed duration forms, stray duration suffixes, illegal ties, invalid track labels, invalid track grouping, lyrics before any score line, and repeated-ending groups without an explicit final ending.
