## Token List

The parser recognizes these tokens. Whitespace and comments are skipped between tokens.

| Token | Accepted source |
| --- | --- |
| `WS` | space or tab |
| `COMMENT` | `;` followed by text up to the line break |
| `IDENTIFIER` | ASCII letter followed by ASCII letters, digits, or `_` |
| `TRACK_LABEL` | `T1` through `T9`, `T11` through `T16` |
| `LYRIC_LABEL` | `L` followed by one or more digits |
| `STRING` | double-quoted string on one line |
| `DIGIT` | `0` through `9` |
| `NOTE` | `1` through `7` |
| `REST` | `0` |
| `DRUM` | `X` |
| `BAR` | `\|` |
| `REPEAT_START` | `\|:` |
| `REPEAT_END` | `:\|` |
| `REPEAT_BOTH` | `:\|:` |
| `LBRACKET` | `[` |
| `RBRACKET` | `]` |
| `SHARPSHARP` | `##` |
| `SHARP` | `#` |
| `FLATFLAT` | `bb` |
| `FLAT` | `b` |
| `NATURAL` | `%` |
| `HALF` | `/` |
| `DOT` | `.` |
| `DASH` | `-` |
| `LOWER` | `,` |
| `HIGHER` | `'` |
| `TIE` | `~` |
| `EQUALS` | `=` |
| `NEWLINE` | `\n`, `\r\n`, or `\r` |
| `EOF` | end of file |
