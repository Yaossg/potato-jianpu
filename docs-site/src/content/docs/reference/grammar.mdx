## Token List

The parser recognizes these tokens. Whitespace and comments are skipped between tokens.

| Token | Accepted source |
| --- | --- |
| `WS` | space or tab |
| `COMMENT` | `;` followed by text up to the line break |
| `IDENTIFIER` | ASCII letter followed by ASCII letters, digits, or `_` |
| `TEXT_KEY` | `title`, `subtitle`, or `composer` |
| `KEY_SIGNATURE` | supported key names such as `C`, `F#`, or `Bb` |
| `TIME_SIGNATURE` | supported fractions such as `4/4`, `6/8`, or `2/16` |
| `NUMBER` | positive finite number |
| `BOOLEAN` | `true` or `false` |
| `PROGRAM_NUMBER` | integer `0` through `127` |
| `DEFAULT_PROGRAM_NUMBER` | integer `0` through `174` |
| `PERCUSSION_PROGRAM_NUMBER` | integer `128` through `174` |
| `PROGRAM_NAME` | quoted melodic General MIDI program name |
| `VOLUME_NUMBER` | number from `0` to `2`, or percentage from `0%` to `200%` |
| `MELODIC_TRACK_LABEL` | `T1` through `T9`, `T11` through `T16` |
| `PERCUSSION_TRACK_LABEL` | `P` followed by one or more digits |
| `LYRIC_LABEL` | `L` followed by one or more digits |
| `STRING` | double-quoted string on one line |
| `DIGIT` | `0` through `9` |
| `NOTE` | `1` through `7` |
| `REST` | `0` |
| `DRUM` | `X` |
| `BAR` | `\|` |
| `REPEAT_START` | `\|:` |
| `REPEAT_END` | `:\|` |
| `REPEAT_BOTH` | `:\|:` |
| `LBRACKET` | `[` |
| `RBRACKET` | `]` |
| `SHARPSHARP` | `##` |
| `SHARP` | `#` |
| `FLATFLAT` | `bb` |
| `FLAT` | `b` |
| `NATURAL` | `%` |
| `HALF` | `/` |
| `DOT` | `.` |
| `DASH` | `-` |
| `LOWER` | `,` |
| `HIGHER` | `'` |
| `TIE` | `~` |
| `VELOCITY` | `ppp`, `pp`, `p`, `mp`, `mf`, `f`, `ff`, or `fff` |
| `CRESCENDO` | `<` |
| `DIMINUENDO` | `>` |
| `EQUALS` | `=` |
| `NEWLINE` | `\n`, `\r\n`, or `\r` |
| `EOF` | end of file |
