This page is a compact lookup reference. For explanations and examples, use the syntax guide pages in the sidebar.

| Construct | Syntax |
| --- | --- |
| Header field | `name: "value"` |
| Separator | `=`, `==`, `===` |
| Note | `1` through `7` |
| Rest | `0` |
| Drum note | `X` |
| Accidental | `#`, `##`, `b`, `bb`, `%` |
| Octave suffix | `1'`, `1''`, `1,`, `1,,` |
| Measure octave prefix | `' 1 2 3`, `, 1 2 3` |
| Duration | `-`, `--`, `/`, `//`, `.`, `/.` |
| Chord | `{1 3 5}` |
| Tie | `~1` |
| Measure separator | `|` |
| Repeat start | `|:` |
| Repeat end | `:|` |
| Repeat end/start | `:|:` |
| Repeated ending | `[1]`, `[2]`, `[1,3]` |
| Track label | `T1:` through `T16:`, except `T10:` |
| Lyric line | `L1: "lyrics"` or `"lyrics"` |
| Comment | `; comment` |

A header exists only when a separator line is present. Without that separator, the whole file is score text. Consecutive bar tokens create an empty measure warning, and the empty measure is ignored.

Track labels are `T1:` through `T9:` and `T11:` through `T16:`. `T10:` is reserved for drums and is rejected as a score-line label.

```jpu valid
title: "Repeat Example"
time: "4/4"
=
|: 1 2 3 4 | [1] 5 - 5 - :| [2] 1 - - -
```
