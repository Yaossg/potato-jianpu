诊断已经放到会触发它们的语法页面里说明。这个页面只作为旧链接或搜索结果落到这里时使用的紧凑索引。

| 诊断范围 | 查看页面 |
| --- | --- |
| 文件头字段、字符串、`key`、`time`、`tempo` | [文件头](../header/) |
| 音符、鼓音、变音、八度、和弦、空和弦、延音线 | [音符与休止符](../notes/) |
| 时值后缀和小节时值警告 | [节奏](../rhythm/) |
| 反复小节线和反复结尾 | [反复](../repeats/) |
| 歌词数量、歌词位置、轨道标签、轨道分组 | [歌词与多轨](../lyrics-tracks/) |

CLI 仍然是查看某个文件完整诊断列表的最好方式：

```sh
pnpm run cli -- validate path/to/score.jpu
```
