文件头按行书写。把它放在 `=` 分隔行之前。

```jpu valid
title: "Evening Song"
subtitle: "Short Study"
composer: "Anonymous"
key: "G"
time: "3/4"
tempo: "72"
=
5 6 5 | 3 - -
```

已知字段包括：

| 字段 | 含义 |
| --- | --- |
| `title` | 渲染在乐谱上方的主标题。 |
| `subtitle` | 副标题文本。 |
| `composer` | 作曲者或来源文本。 |
| `key` | 用于播放和导出的调号。 |
| `time` | 用于小节时值校验的拍号。 |
| `tempo` | 播放和 MIDI 的速度。 |
| `hidden` | 不需要渲染出来的文件头字段。 |

未知字段会作为元数据保留。除非未来版本赋予它们含义，否则它们不会改变解析、渲染、播放或导出行为。

文件头值使用带引号的字符串。转义文本会按源文本保留，所以请按希望用户读到的样子书写可见元数据。

```jpu valid
title: "Evening Song"
composer: "Anonymous"
tempo: "72"
=
1 2 3 4
```

字段名必须以字母开头，后面可以继续使用字母、数字或下划线。文件头字符串必须在同一行结束。

<JianpuExample title="未结束的文件头字符串" status="invalid" statusLabel="错误" description="title 字符串没有闭合，所以文档无效。">

```jpu invalid
title: "Open title
=
1 2 3 4
```

</JianpuExample>

`key` 字段接受自然调和带变音的调名，例如 `C`、`G`、`F`、`#F`、`F#`、`bB`、`Bb`。它会影响播放和导出的音高；无效调名会产生诊断。

`time` 字段使用 `拍数/拍单位`，例如 `4/4`、`3/4`、`6/8`。它用于小节时值校验。小节时值和拍号不一致时会产生警告，而不是硬解析失败。

`tempo` 字段是正数 BPM。它用于播放、MIDI 导出和音频导出。

使用 `hidden` 可以让某些文件头元数据保留在文档中，但不渲染到 SVG 里。

```jpu valid
title: "Practice Line"
composer: "Anonymous"
hidden: "composer"
=
1 2 3 4
```

文件头也可以给轨道和歌词行命名。这里使用的标签文本应和乐谱主体中的标签一致。

```jpu valid
T1: "Melody"
T2: "Harmony"
L1: "Verse"
=
T1: 1 2 3 4
T2: 5 5 5 5
L1: "do re mi fa"
```
