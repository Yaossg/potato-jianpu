## 文件头基础

文件头按行书写。把它放在 `=` 分隔行之前。

## 字段

已知字段包括：

| 字段 | 含义 |
| --- | --- |
| `title` | 渲染在乐谱上方的主标题。 |
| `subtitle` | 副标题文本。 |
| `composer` | 作曲者或来源文本。 |
| `key` | 用于播放和导出的调号。 |
| `time` | 用于小节时值校验的拍号。 |
| `tempo` | 播放和 MIDI 速度。 |
| `hidden` | 隐藏渲染出的文件头区块的布尔标记。 |
| `program` | 播放和导出的乐谱级默认 Program。 |
| `volume` | 播放和导出的乐谱级默认轨道音量。 |
| `Tn.program` | 旋律轨道的逐轨道播放和导出 Program 覆盖。 |
| `Tn.volume` | 逐轨道播放和导出音量倍率。 |

`title`、`subtitle` 和 `composer` 的默认值为空；`hidden` 默认为 `false`，`key` 默认为 `C`，`time` 默认为 `4/4`，`tempo` 默认为 `120`，`program` 会回退到浏览器或 CLI 的 Program 设置，`volume` 默认为 `1`。

只接受文档列出的文件头字段。`arranger` 这样的未知字段，或 `temop` 这样的拼写错误字段，都会成为解析错误。

## 字符串和校验

文本字段使用双引号字符串，并且必须保持在同一行。反斜杠会让分词器跳过后面的一个字符，但反斜杠本身会作为源文本保留，不会被解释成转义序列。因此请按希望用户读到的样子书写可见元数据。

<JianpuSource
  title="带引号的文件头源码"
  source={`title: "Evening Song"
composer: "Anonymous"
tempo: 72
=
1 2 3 4`}
/>

<ScorePreview
  title="渲染后的带引号文件头"

composer: "Anonymous"
tempo: 72
=
1 2 3 4`}
/>

文件头字段名区分大小写。文本值和可见标签名称必须加引号；`key`、`time`、`tempo` 和 `hidden` 使用不加引号的类型化值。文件头字符串必须在同一行结束。

  source={`title: "Open title
=
1 2 3 4`}
/>

`key` 字段接受 `C`、`C#`、`Db`、`D`、`D#`、`Eb`、`E`、`F`、`F#`、`Gb`、`G`、`G#`、`Ab`、`A`、`A#`、`Bb` 和 `B`。也可以写成 `#F` 或 `bB` 这样的变音在前形式。它会影响播放和导出的音高；无效调名会产生诊断。

## 音乐默认值

`time` 字段使用 `拍数/拍单位`，例如 `4/4`、`3/4` 或 `6/8`。允许的分子是 `2`、`3`、`4`、`6`、`9` 和 `12`；允许的分母是 `2`、`4`、`8` 和 `16`。它用于小节时值校验。小节时值和拍号不一致时会产生警告，而不是硬解析失败。

`tempo` 字段是正的 BPM，可以是 `96`、`120` 或 `132.5` 这样的整数或小数。它用于播放、MIDI 导出和音频导出。

`program` 字段设置播放和导出的乐谱级默认 Program。数字值可以是 `0` 到 `220`；`128..220` 会启用和浏览器、CLI Program 控件相同的鼓模式。也可以使用带引号的旋律 Program 名称。只有文件头省略 `program` 时，才会使用浏览器或 CLI 的 Program 控件。

`volume` 字段设置乐谱级默认轨道音量。值可以是 `0` 到 `2` 的数字，也可以是 `0%` 到 `200%` 的百分数；`1` 和 `100%` 都表示不变。它是没有 `Tn.volume` 的轨道默认值，不会和 `Tn.volume` 叠加相乘。

## 隐藏文件头

使用 `hidden: true` 可以让整块渲染文件头从 SVG 中隐藏，同时把元数据保留在文档里。使用 `hidden: false` 或省略该字段时，会正常渲染文件头。

## 轨道和歌词标签

文件头也可以给轨道和歌词行命名。轨道名称可以写成 `Tn.name` 或简写 `Tn`；歌词标签可以写成 `Ln.name` 或简写 `Ln`。

只有一条未写 `T1:` 的音乐行时，`T1.name` 也会命名这条渲染行。

<JianpuSource
  title="轨道和歌词标签源码"
  source={`T1.name: "Melody"
T2: "Harmony"
L1.name: "Verse"
=
T1: 1 2 3 4
T2: 5 5 5 5
L1: "do re mi fa"`}
/>

## 轨道 Program

在文件头中使用 `Tn.program`，可以为带标签的编排轨道指定旋律 General MIDI Program。值可以是 `0` 到 `127` 的整数，也可以是浏览器 Program 选择器中的带引号 Program 名称。带引号名称会先去掉首尾空白，再按不区分大小写的方式匹配。

`Tn.program` 会覆盖该轨道的乐谱级 `program` 默认值。只有文件头省略 `program` 时，浏览器和 CLI 的 Program 控件才作为默认值。只有一条未写 `T1:` 的音乐行时，`T1.program` 会应用到这条播放/导出轨道。`T10.program` 和鼓 Program 值保留给后续鼓轨道设计。

<JianpuSource
  title="轨道 Program 源码"
  source={`T1.name: "Melody"
T1.program: 0
T2.name: "Violin"
T2.program: "Violin"
=
T1: 1 2 3 4
T2: 5, 6, 7, 1`}
/>

## 轨道音量

在文件头中使用 `Tn.volume`，可以设置单个播放/导出轨道的音量。值可以是 `0` 到 `2` 的数字，也可以是 `0%` 到 `200%` 的百分数；`1` 和 `100%` 表示不变，`0.5` 和 `50%` 表示半音量，`0` 和 `0%` 表示静音，`2` 和 `200%` 表示在限幅前把该轨道的力度/增益加倍。

`Tn.volume` 会覆盖该轨道的乐谱级 `volume` 默认值，而不是和它相乘。解析出的轨道音量会和浏览器音量滑杆或 CLI 音频 `--amplitude` 叠加使用，而不是替代主音量。MIDI 导出中，解析出的轨道音量会缩放该轨道的音符力度。浏览器播放、WAV 和 MP3 中，主音量/振幅和逐轨道音量都会生效。

只有一条未写 `T1:` 的音乐行时，`T1.volume` 会应用到这条播放/导出轨道。
