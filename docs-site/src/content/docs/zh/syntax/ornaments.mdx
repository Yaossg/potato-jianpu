## 波音

Modern Jianpu Markup 目前支持上波音和下波音。把装饰音紧接在单个音高音符后面，并写在所有时值后缀之前。

使用 `(^)` 表示上波音，使用 `(v)` 表示下波音。

<JianpuSource
  title="波音源码"
  source={`time: 4/4
===
1(^) 2(v) 3 - | 5(^)/ 5(v)/ 1' - 0`}
/>

<ScorePreview
  title="渲染后的波音"
  source={`time: 4/4
===
1(^) 2(v) 3 - | 5(^)/ 5(v)/ 1' - 0`}
/>

这个后缀要写在延音线、减时斜线、附点或其他时值标记之前。

<JianpuSource title="波音写在时值后缀之前" source={`1(^)- 1(v)/ 2(^).`} />

波音只能附着在普通的单个音高音符上。当前版本不支持把波音写在休止符、打击乐音符、和弦或连音音符上。

## 回音

回音使用同样的音符后缀位置。使用 `(z)` 表示普通回音，使用 `(s)` 表示逆回音。

<JianpuSource
  title="回音源码"
  source={`time: 4/4
===
1(z) 2(s) 3 - | 5(z)/ 5(s)/ 1' - 0`}
/>

<ScorePreview
  title="渲染后的回音"
  source={`time: 4/4
===
1(z) 2(s) 3 - | 5(z)/ 5(s)/ 1' - 0`}
/>

和波音一样，回音只能附着在普通的单个音高音符上，并且要写在所有时值后缀之前。

## 颤音

使用 `(tr)` 表示颤音。它附着在左侧的主音上，并写在所有时值后缀之前。

<JianpuSource
  title="颤音源码"
  source={`time: 4/4
===
1(tr) 2(tr) 3 - | 5(tr)/ 5(tr)/ 1' - 0`}
/>

<ScorePreview
  title="渲染后的颤音"
  source={`time: 4/4
===
1(tr) 2(tr) 3 - | 5(tr)/ 5(tr)/ 1' - 0`}
/>

颤音只能附着在普通的单个音高音符上。上方辅助音会按照当前调号以及该小节内对相应音级生效的临时升降号来确定。

## 倚音

倚音也写成音符后的装饰音后缀。后缀始终附着在左侧的音高音符上。使用 `(<...)` 表示渲染和播放在主音之前的前倚音，使用 `(>...)` 表示渲染和播放在主音之后的后倚音。

<JianpuSource
  title="倚音源码"
  source={`time: 4/4
===
1(<2) 2(>3) 3(<45) 5(>6')`}
/>

<ScorePreview
  title="渲染后的倚音"
  source={`time: 4/4
===
1(<2) 2(>3) 3(<45) 5(>6')`}
/>

倚音后缀内部可以写 1、2、4 或其他 2 的幂个音高音符，并沿用普通的变音记号和八度语法。一个倚音渲染为带一条横线的八分音符，两个倚音渲染为各带两条横线的十六分音符，四个倚音渲染为各带三条横线，依此类推。不要在倚音后缀里写休止符、打击乐音符、和弦、延音线、力度或时值标记。

和波音一样，当前版本的倚音只能附着在普通的单个音高音符上。

## 播放与导出

播放、MIDI、WAV 和 MP3 导出会把每个波音展开成很短的“主音-邻音-主音”，然后继续保留该音符剩余的时值。

上波音使用上方相邻音级，下波音使用下方相邻音级。邻音会按照当前调号以及该小节内对同一音级生效的临时升降号来确定。

播放、MIDI、WAV 和 MP3 导出会把回音展开成四个很短的音，然后继续保留该音符剩余的时值。普通回音播放为“上邻音-主音-下邻音-主音”。逆回音播放为“下邻音-主音-上邻音-主音”。

播放、MIDI、WAV 和 MP3 导出会把颤音展开到完整的书写时值中。颤音从主音开始，以三十二分音符密度在主音和上方辅助音之间交替，并且至少保留一组完整的“主音-辅助音”。

播放、MIDI、WAV 和 MP3 导出会把倚音展开在主音的书写时值之内。前倚音先发声，再播放缩短后的主音；后倚音使用主音时值的尾部。多个倚音会平均分配倚音时值。

SVG、PNG 和 PDF 导出会使用内置的 SMuFL 装饰音字体，把波音、回音和颤音渲染在音符上方。倚音会渲染为主音旁的小号简谱数字：前倚音在左侧，后倚音在右侧。每组倚音下方带一条或多条短横线，横线下沿用四分之一圆弧连接到主音。下载的 SVG 和 PDF 会嵌入 SMuFL 装饰音符号所需的字体。
