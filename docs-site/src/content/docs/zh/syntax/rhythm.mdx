普通音符在常见的 `4/4` 拍中按四分音符单位填充小节。

```jpu valid
time: "4/4"
=
1 2 3 4
```

横线会延长前一个音符或休止符。

```jpu valid
time: "4/4"
=
1 - 2 -
```

斜线会缩短音符。一个斜线把时值减半，更多斜线继续二分。

```jpu valid
time: "4/4"
=
1/ 2/ 3 4 5
```

附点会增加前一层时值的一半。

```jpu valid
time: "6/8"
=
1. 2/ 3/ 4/
```

横线时值和斜线时值是两种不同形式。不要在同一个音符上混用它们。

| 写法 | 时值 |
| --- | --- |
| `1` | 四分音符 |
| `1-` | 二分音符 |
| `1--` | 附点二分音符 |
| `1---` | 全音符 |
| `1/` | 八分音符 |
| `1//` | 十六分音符 |
| `1///` | 三十二分音符 |
| `1.` | 附点四分音符 |
| `1..` | 复附点四分音符 |
| `1/.` | 附点八分音符 |

时值标记属于它前面的音符、休止符、鼓音或和弦。没有前置对象的游离时值标记是无效的。

```jpu valid
time: "4/4"
=
{1 3 5} - 0/ 1.
```

<JianpuExample title="混合时值形式" status="invalid" description="横线延长和斜线/附点后缀不能混在同一个项目上。">

```jpu invalid
1-/ 2 3 4
```

</JianpuExample>

<JianpuExample title="游离时值标记" status="invalid" description="时值后缀必须跟在音符、休止符、鼓音或和弦之后。">

```jpu invalid
/1 2 3 4
```

</JianpuExample>

小节时值警告使用当前 `time` 文件头。警告表示文档仍然可以渲染，但该小节比声明的拍号更长或更短。

<JianpuExample title="小节过短" status="warning" description="在 4/4 中，这个小节比声明的拍号短。">

```jpu warning
time: "4/4"
=
1 2
```

</JianpuExample>
