## 斜线和附点时值

斜线会缩短音符。一个斜线把时值减半，更多斜线继续二分。

<JianpuSource
  title="斜线时值源码"
  source={`time: 4/4
===
1/ 2/ 3 4 5`}
/>

<ScorePreview
  title="斜线时值"
  source={`time: 4/4
===
1/ 2/ 3 4 5`}
/>

附点会增加前一层时值的一半。

  title="附点时值源码"

## 时值表

横线时值和斜线时值是两种不同形式。不要在同一个音符上混用它们。

| 写法 | 时值 |
| --- | --- |
| `1` | 四分音符 |
| `1-` | 二分音符 |
| `1--` | 附点二分音符 |
| `1---` | 全音符 |
| `1/` | 八分音符 |
| `1//` | 十六分音符 |
| `1///` | 三十二分音符 |
| `1.` | 附点四分音符 |
| `1..` | 复附点四分音符 |
| `1/.` | 附点八分音符 |

时值标记属于它前面的音符、休止符、鼓音或和弦。没有前置对象的游离时值标记是无效的。

## 延音线

前导延音线标记 `~` 会把当前音符连接到前一个兼容音符，并合并它们在播放和导出中的时值。

<JianpuSource
  title="延音线源码"
  source={`1 - - - | ~1 - - -`}
/>

<ScorePreview title="渲染后的延音线" source={`1 - - - | ~1 - - -`} />

延音线目标必须和前一个发声音高兼容。轨道里的第一个音符不能带延音线；带标签轨道的延音线会按轨道分别校验。

<JianpuSource
  title="兼容延音线源码"
  source={`time: 2/4
===
#4 ~4 | X ~X | {1 3 5} ~{1 3 5}`}
/>

<ScorePreview
  source={`time: 2/4
===
#4 ~4 | X ~X | {1 3 5} ~{1 3 5}`}
/>

<JianpuExample
  title="非法延音线"
  status="invalid"
  description="延音线不能出现在轨道开头，不能接在休止符之后，也不能改变目标音高。"
  source={`1 0 ~1`}
/>

小节时值警告使用当前 `time` 文件头。警告表示文档仍然可以渲染，但该小节比声明的拍号更长或更短。

  title="小节过短"

  description="在 4/4 中，这个小节比声明的拍号短。"

===
1 2`}
/>
