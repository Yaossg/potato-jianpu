## 斜线和附点时值

斜线会缩短音符。一个斜线把时值减半，更多斜线继续二分。

  title="斜线时值源码"

===

/>

  title="斜线时值"

1/ 2/ 3 4 5`}
/>

## 时值表

横线时值和斜线时值是两种不同形式。不要在同一个音符上混用它们。

| 写法 | 时值 |
| --- | --- |
| `1` | 四分音符 |
| `1-` | 二分音符 |
| `1--` | 附点二分音符 |
| `1---` | 全音符 |
| `1/` | 八分音符 |
| `1//` | 十六分音符 |
| `1///` | 三十二分音符 |
| `1.` | 附点四分音符 |
| `1..` | 复附点四分音符 |
| `1/.` | 附点八分音符 |

时值标记属于它前面的音符、休止符、鼓音或和弦。没有前置对象的游离时值标记是无效的。

## 延音线

前导延音线标记 `~` 会把当前音符连接到前一个兼容音符，并合并它们在播放和导出中的时值。

<JianpuSource
  title="延音线源码"
  source={`1 - - - | ~1 - - -`}
/>

<ScorePreview title="渲染后的延音线" source={`1 - - - | ~1 - - -`} />

延音线目标必须和前一个发声音高兼容。轨道里的第一个音符不能带延音线；带标签轨道的延音线会按轨道分别校验。

<JianpuSource
  title="兼容延音线源码"
  source={`time: 2/4
===
#4 ~4 | X ~X | {1 3 5} ~{1 3 5}`}
/>

<ScorePreview
  source={`time: 2/4
===
#4 ~4 | X ~X | {1 3 5} ~{1 3 5}`}
/>

<JianpuExample
  title="非法延音线"
  status="invalid"
  description="延音线不能出现在轨道开头，不能接在休止符之后，也不能改变目标音高。"
  source={`1 0 ~1`}
/>

## 圆滑线

使用连续写成的 `$(` 起点和右括号 `)`，在两个或更多音高音符或和弦上绘制圆滑线。圆滑线可以跨小节、源码行和分页，也可以嵌套。

<JianpuSource
  title="圆滑线源码"
  source={`time: 4/4
===
$(1(^) 2 {3 5} 4)`}
/>

<ScorePreview
  title="渲染后的圆滑线"
  source={`time: 4/4
===
$(1(^) 2 {3 5} 4)`}
/>

使用连续写成的 `$$(` 起点，可以在圆滑线水平段中央标注数字。该数字统计圆滑线内的所有音高音符和和弦，包括首尾两个端点；和弦整体计作一个，内部休止符不计数。普通 `$(...)` 圆滑线不显示数字。

<JianpuSource
  title="带计数圆滑线源码"
  source={`time: 4/4
===
$$(1 {2 4} 3 4)`}
/>

<ScorePreview
  title="渲染后的带计数圆滑线"
  source={`time: 4/4
===
$$(1 {2 4} 3 4)`}
/>

圆滑线两端必须是音高音符或和弦。内部可以出现休止符，此时会产生警告但仍绘制圆滑线；圆滑线内不接受鼓音。第一枚音高音符或和弦必须与 `$(` 或 `$$(` 写在同一源码行。

<JianpuSource
  title="嵌套且跨行的圆滑线"
  source={`time: 2/4
===
$($(1 2)
3 4)`}
/>

圆滑线会在浏览器播放、MIDI、WAV 或 MP3 输出中让相邻的不同音高产生短暂连奏重叠，但不会移动原书写起音拍点。休止符会中断连接，同音重复仍分别起音。延音线使用 `~`，连接兼容的重复音高并合并发声时值。两者可以同时出现，较短的延音线会画在更靠近音符的位置。

<JianpuExample
  title="圆滑线内含休止符"
  status="warning"
  description="弧线仍会渲染，但圆滑线内的休止符会产生警告。"
  source={`time: 3/4
===
$(1 0 2)`}
/>

<JianpuExample
  title="圆滑线内的鼓音"
  status="invalid"
  description="圆滑线接受音高音符和和弦，内部可以有休止符，但不能有鼓音。"
  source={`$(1 X 2)`}
/>
