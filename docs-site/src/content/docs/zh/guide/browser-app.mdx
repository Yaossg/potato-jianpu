需要边写边获得即时反馈时，使用浏览器 App。它把源码编辑器、诊断、预览、播放、示例、设置和下载放在同一个本地工作区里，是保存文件或把流程移到 CLI 之前最快的 `.jpu` 语法试验环境。

## 工作区

使用“打开”可以把本地 `.jpu` 文件载入编辑器。如果编辑器里已经有文本，App 会先询问是否覆盖。使用“保存”可以把当前源码文本下载为 `.jpu` 文件；保存源码不要求乐谱已经成功解析。

编辑器会在当前设备的浏览器本地保存草稿。刷新页面会恢复这个草稿，而“保存”会生成一个可以保留、分享或交给 CLI 使用的文件。

清空操作会先要求确认，再移除当前源码。

## 本地草稿

App 会在当前设备的当前浏览器中保存草稿和显示偏好。它不会创建账户，也不会把草稿同步到其他浏览器或设备。清除本站点的浏览器数据可能会移除已保存的草稿和偏好。

请使用保存功能将 `.jpu` 文件保留在浏览器之外。需要备份乐谱、移到其他设备、分享，或交给 CLI 使用时，都应先保存文件。

## 编辑与诊断

源码编辑器接受和 CLI 相同的 `.jpu` 文本。它会显示行号、高亮当前行，并可以根据编辑器设置换行或保留长源码行。

诊断会显示在编辑器下方，也会在源码中高亮，并在受影响的行号旁显示红色或黄色标记。点击一条诊断或行号旁的标记可以聚焦到对应范围。错误会阻止新的渲染结果生成，但预览区会保留上一份有效乐谱，并显示预览已过期的提示，方便一边对照一边修正源码。警告不会阻止使用乐谱，但表示需要确认的行为，例如小节时值不匹配。

## 预览与播放

首次使用时会显示音源下载进度，随后显示音频准备状态。无法获取下载总大小时，只显示已下载 MB，不显示百分比。停止播放会收起对应的进度提示，下载继续以供复用。加载失败后，可以再次播放或导出以重试。

浏览器存储可用时，下载完成的音源会跨刷新保存，并由同一站点的应用和文档共享。命中缓存时不会显示下载动画。编辑乐谱、切换乐器和普通应用更新不会使它失效；音源版本改变时才需要重新下载。清除站点数据、浏览器回收存储或退出隐私会话可能删除缓存。不同站点地址或浏览器配置使用独立存储。这让音源可以离线复用；离线打开应用本身仍要求页面和音频引擎资源可用。

预览使用和 CLI 相同的解析器与渲染器，因此浏览器和终端里的语法行为保持一致。预览摘要会显示渲染出的谱面行数、当前页面宽度，以及宽度来自预览面板、内容推断、手动设置还是纸张预设。

使用播放按钮可以试听当前乐谱。播放过程中，正在发声的音符会在渲染预览中高亮。也可以点击渲染出的某个音符，从该音符开始播放。修改源码、加载示例或停止播放都会清除当前高亮。

浏览器播放使用和 MIDI、WAV、MP3 导出相同的计时与声音模型。Program、鼓音、音量、力度、反复和轨道行为以“播放”指南为准。

## 示例

示例面板会把内置 `.jpu` 乐谱载入编辑器。如果编辑器里已经有文本，App 会先询问是否覆盖。加载示例会停止播放并关闭示例面板；载入后的源码会像普通草稿一样继续编辑。

示例适合作为可编辑的起点：载入一份，修改源码，再用诊断和预览反馈理解语法行为。

## 页面布局与设置

页面设置控制视觉预览和视觉下载：纸张预设、方向、宽度模式、页面尺寸、页边距、页码、小节编号、记谱颜色、背景和对齐方式。`paginate`、`measureNumbers` 和 `footer` 等文件头字段也可以为一份乐谱提供视觉输出默认值。

两端对齐只改变视觉间距；不会修改 `.jpu` 源码、播放时值或 MIDI、音频输出。选择“无”会保留自然的小节间距；选择“除末行外”会拉伸除最后一行外的每条视觉谱行；选择“所有行”会拉伸每条视觉谱行。所选模式同时用于预览和视觉下载。

当输出需要适配 A4、B5 或 Letter 纸张时，选择纸张预设与方向。只有目标需要特定页面尺寸时才使用自定义宽度和高度。开启分页后，预览与视觉下载会使用固定高度页面；页边距、页码和文件头提供的页脚文本都会在每页内预留空间。

编辑器设置控制源码编辑偏好：源码自动换行、编辑器字号、行号、当前行高亮和源码内诊断高亮。

声音设置控制浏览器播放和浏览器渲染的音频下载：默认 Program、主音量、忽略开头休止符和试听。导出设置控制 PNG 倍率与像素尺寸、拆分页 SVG/PNG 下载，以及 WAV 和 MP3 渲染使用的音频采样率。PNG 默认使用 `2x`、采用内置导出字体，并且始终以不透明背景下载。

语言和主题按钮位于顶部工具栏。语言偏好、主题偏好、源码文本、编辑器显示偏好和编辑器/预览分栏宽度都会保存在浏览器本地。

## 下载

导出菜单可以把当前有效乐谱下载为 SVG、PNG、PDF、MIDI、WAV 或 MP3。SVG、PNG 和 PDF 使用当前页面设置。MIDI、WAV 和 MP3 使用共享播放模型，并在适用时使用当前声音设置。

即使乐谱正在播放，SVG、PNG 和 PDF 下载也不会包含播放高亮。如果导出字体下载失败，网络恢复后可以再次导出以重试。WAV 和 MP3 使用与预览播放相同的完整 `0–200%` 主音量范围，包括静音。

想让预览和视觉下载使用固定高度页面时，在页面设置里启用“分页”。想让 SVG 或 PNG 按每个渲染页分别下载文件时，在导出设置里启用“拆分页”。

音频导出通常比图片或 MIDI 导出更久，因为浏览器需要先渲染完整编排再下载。渲染 WAV 或 MP3 时，导出菜单会显示事件数量和大致时长。

在导出菜单选择“MP4（实验）”，可下载带声音和同步高亮的简谱播放区域视频。画面自动跟随谱行；支持时使用 MP4，否则尝试 WebM。进度条旁可取消。详见[导出指南](../export/)。

## 帮助

帮助按钮会打开本地化文档首页：英文为 `/docs/`，简体中文为 `/docs/zh/`。从那里可以进入语法页面查看记谱规则，进入 CLI 指南了解可重复的终端流程，进入播放指南了解计时与声音行为，也可以查看导出指南了解各格式输出行为。
