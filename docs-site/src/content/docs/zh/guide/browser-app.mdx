## 基本流程

1. 在编辑器里写源码。
2. 查看诊断中的错误和警告。
3. 预览渲染后的 SVG。
4. 使用播放，或点击渲染后的音符试听乐谱。
5. 从导出菜单下载 SVG、PNG、MIDI、WAV 或 MP3。

预览使用和 CLI 相同的解析器与渲染器，因此浏览器和终端里的语法行为保持一致。

## 设置

页面设置控制视觉输出，例如页面宽度、乐谱颜色和背景。声音设置控制播放与音频导出，包括音色、音量、音频采样率，以及是否忽略开头休止符。

修改源码会停止当前播放。加载示例也会停止播放并关闭示例面板。
