需要边写边获得即时反馈时，使用浏览器 App。它把编辑、校验、预览、播放和导出放在同一个本地工作区里，适合在另存或脚本化 `.jpu` 文件之前快速试语法。

## 编辑与诊断

源码编辑器接受和 CLI 相同的 `.jpu` 文本。它会显示行号、高亮当前行，并可以根据编辑器设置换行或保留长源码行。源码会保存在浏览器本地存储里，因此在同一台设备上刷新页面后仍会保留草稿。

诊断会显示在编辑器下方，也会在源码中高亮，并在受影响的行号旁显示红色或黄色标记。点击一条诊断或行号旁的标记可以聚焦到对应范围。错误会阻止新的渲染结果生成，但预览区会保留上一份有效乐谱，并显示预览已过期的提示，方便一边对照一边修正源码。警告不会阻止使用乐谱，但表示需要确认的行为，例如小节时值不匹配。

清空操作会先要求确认，再移除当前源码。

## 预览与播放

预览使用和 CLI 相同的解析器与渲染器，因此浏览器和终端里的语法行为保持一致。预览摘要会显示渲染出的谱面行数、当前页面宽度，以及宽度来自预览面板、内容推断还是手动设置。

使用播放按钮可以试听当前乐谱。播放过程中，正在发声的音符会在渲染预览中高亮。也可以点击渲染出的某个音符，从该音符开始播放。修改源码、加载示例或停止播放都会清除当前高亮。

播放使用共享的编排编译器，因此音符、休止符、和弦、延音线、反复、反复结尾、带标签轨道、调号、乐谱级与逐轨道 Program、乐谱级与逐轨道音量、鼓音程序都遵循 MIDI、WAV、MP3 导出使用的同一套计时规则。

`program`、`volume`、`Tn.program` 和 `Tn.volume` 这样的乐谱级轨道设置也会进入同一套播放和导出规则。

## 示例

示例面板会把内置 `.jpu` 乐谱载入编辑器。如果编辑器里已经有文本，App 会先询问是否覆盖。加载示例会停止播放并关闭示例面板；载入后的源码会像普通草稿一样继续编辑。

## 导出

导出菜单可以把当前有效乐谱下载为 SVG、PNG、PDF、MIDI、WAV 或 MP3。SVG、PNG 和 PDF 使用当前页面设置：宽度、分页、页高、页边距、页码、颜色、背景和对齐方式；分页和页脚文字也可以来自 `paginate` 与 `footer` 文件头字段。MIDI 使用当前默认 Program、乐谱里的 `program`/`volume` 默认值、`Tn.program`/`Tn.volume` 覆盖值，以及忽略开头休止符设置。WAV 与 MP3 会把浏览器主音量和解析出的轨道音量一起用于本地渲染。

音频导出通常比图片或 MIDI 导出更久，因为浏览器需要先渲染完整编排再下载。渲染 WAV 或 MP3 时，导出菜单会显示事件数量和大致时长。

## 设置

页面设置控制视觉输出：

- 宽度模式：匹配预览面板、根据谱面内容推断宽度，或使用手动像素宽度。
- 颜色和页面：设置记谱颜色以及 SVG/PNG/PDF 背景。
- 对齐：保留自然间距、对齐除最后一行之外的所有行，或对齐每一行。

编辑器设置控制源码编辑偏好：

- 源码自动换行：换行长源码行，或保留水平滚动。
- 编辑器字号：同时调整源码、行号和源码高亮的大小。
- 显示行号：显示或隐藏编辑器边栏。
- 高亮当前行：显示或隐藏当前源码行背景。
- 高亮诊断：显示或隐藏源码内的诊断高亮，但保留诊断列表。

声音设置控制播放与音频导出：

- 音色：选择默认 General MIDI Program，或选择没有 `Tn.program` 的轨道所使用的鼓音程序。
- 音量：调整浏览器播放和浏览器渲染的 WAV/MP3 输出。
- 音频采样率：选择 WAV/MP3 渲染采样率。
- 忽略开头休止符：从开头播放时跳过共享的前导静音。
- 试听：用当前声音播放一段短句。

语言和主题按钮位于顶部工具栏。语言偏好、主题偏好、源码文本、编辑器显示偏好和编辑器/预览分栏宽度都会保存在浏览器本地。

## 帮助

帮助按钮会打开本地化文档首页：英文为 `/docs/`，简体中文为 `/docs/zh/`。从那里可以进入语法页面查记谱规则，用 CLI 指南了解如何查看警告和错误，也可以查看导出指南了解各格式行为。
