## 浏览器播放

浏览器 App 使用 WebAudioTinySynth。播放会增量调度音符，高亮当前发声的渲染音符，并在源码变化时停止。

点击播放从渲染音符的元数据开始。如果点击的是第一个播放音符，并且开启了忽略开头休止符，前导休止会被跳过。

文档中的渲染预览也使用同一套播放编译器。带播放控件的预览支持点击渲染出的音符，并从被点击的音符开始播放。

## 音色与鼓音

程序号 `0..127` 使用旋律 TinySynth 音色。程序号 `128..174` 使用鼓模式。在鼓模式中，源码里的 `X` 会映射到打击乐音符 `program - 128 + 35`。

使用 `program` 可以设置乐谱级默认 Program；使用 `Tn.program` 可以给带标签轨道指定旋律 Program，并覆盖该轨道的 `program` 默认值。逐轨道旋律 Program 的数字值只能是 `0..127`，带引号名称会通过浏览器选择器使用的同一份 General MIDI Program 列表解析。只有文件头省略 `program` 时，浏览器和 CLI 的 Program 控件才作为默认值。

在打击乐轨道（标有 `P1:`、`P2:` 等的行）上使用 `Pn.program`（`128`–`174`）来指定打击乐 Program。每条 P 轨道演奏自己的 GM 打击乐音色，并与其它 P 轨道共享 MIDI 通道 10。多条 P 轨道可以让你在同一个乐谱里编写完整的架子鼓编排。浏览器 App 中有一个完整的鼓组示例。

使用 `volume` 可以设置乐谱级默认轨道音量；使用 `Tn.volume` 可以把单个轨道覆盖为 `0` 到 `2`，也可以写成 `0%` 到 `200%`。解析出的轨道音量会和浏览器音量滑杆相乘，所以主音量变化时，较轻的轨道仍保持相对较轻。

逐音符力度标记会在应用轨道音量之前设置音符力度。渐强、渐弱会在两个端点之间插值音符力度；如果端点写有明确的力度标记，该标记会成为插值目标。

浏览器 App 的声音设置包含音色选择、音量、试听，以及忽略开头休止符开关。

## 反复与轨道

反复小节线和反复结尾会在播放和导出时展开。带标签轨道会在同一个声部组内同时播放；下一个声部组会在前一个组结束后开始。

歌词只参与视觉渲染，不影响播放计时。
