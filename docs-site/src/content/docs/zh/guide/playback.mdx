## 浏览器播放

浏览器 App 使用 WebAudioTinySynth。播放会增量调度音符，高亮当前发声的渲染音符，并在源码变化时停止。

点击播放从渲染音符的元数据开始。如果点击的是第一个播放音符，并且开启了忽略开头休止符，前导休止会被跳过。

文档中的渲染预览也使用同一套播放编译器。带播放控件的预览支持点击渲染出的音符，并从被点击的音符开始播放。

## 音色与鼓音

程序号 `0..127` 使用旋律 TinySynth 音色。程序号 `128..220` 使用鼓模式。在鼓模式中，源码里的 `X` 会映射到打击乐音符 `program - 128 + 35`。

使用 `Tn.volume` 可以把单个轨道缩放到 `0` 到 `2`。它会和浏览器音量滑杆相乘，所以主音量变化时，较轻的轨道仍保持相对较轻。

浏览器 App 的声音设置包含音色选择、音量、试听，以及忽略开头休止符开关。

## 反复与轨道

反复小节线和反复结尾会在播放和导出时展开。带标签轨道会在同一个声部组内同时播放；下一个声部组会在前一个组结束后开始。

歌词只参与视觉渲染，不影响播放计时。
