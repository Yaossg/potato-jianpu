需要可重复检查和脚本化导出时，使用 CLI。

```sh
pnpm run cli -- --version
pnpm run cli -- validate examples/twinkle.jpu
pnpm run cli -- parse examples/twinkle.jpu
```

`validate` 会报告诊断而不写出文件。`parse` 会打印解析后的文档数据，方便检查。

## 导出命令

```sh
pnpm run cli -- export-svg examples/twinkle.jpu -o twinkle.svg
pnpm run cli -- export-png examples/twinkle.jpu -o twinkle.png
pnpm run cli -- export-pdf examples/twinkle.jpu -o twinkle.pdf
pnpm run cli -- export-midi examples/twinkle.jpu -o twinkle.mid
pnpm run cli -- export-wav examples/twinkle.jpu -o twinkle.wav
pnpm run cli -- export-mp3 examples/twinkle.jpu -o twinkle.mp3
```

SVG、PNG 和 PDF 导出支持 `--page-width <px>`、`--page-height <px>`、`--page-margin <px>`、`--page-footer <text>`、`--page-numbers`、`--color <css>` 和 `--background <css>`。SVG 和 PNG 导出还支持 `--split-pages`；使用 `-o score.svg` 时，拆页输出会写出 `score-01.svg`、`score-02.svg` 等文件，并且不会覆盖已有分页文件。

MIDI、WAV 和 MP3 导出支持 `--program <number>` 和 `--omit-initial-rest`。`--program` 是没有乐谱级 `Tn.program` 文件头的轨道所使用的默认 Program。WAV 和 MP3 还支持 `--sample-rate <hz>` 与 `--amplitude <0-1>`。MP3 另外支持 `--bit-rate <kbps>`。

程序号 `0..127` 是旋律 General MIDI 音色。程序号 `128..174` 会启用鼓模式，把 `X` 映射到打击乐音符 `program - 128 + 35`。
