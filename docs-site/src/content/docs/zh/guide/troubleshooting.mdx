---
title: 故障排查
description: 理解常见诊断以及对应修复方式。
docId: guide-troubleshooting
---

诊断分为错误和警告。错误会让文档无法被接受。警告表示乐谱仍然可以渲染、播放或导出，但通常需要注意。

## 小节时值警告

小节时值会和当前 `time` 文件头比较。小节过短或过长是警告，不是解析错误。

```jpu warning
time: "4/4"
=
1 2
```

可以通过补足缺少的时值、修改音符长度，或调整 `time` 文件头来修复。

## 空小节

连续的小节线 token 会在中间产生空小节。空小节会被忽略，并报告为警告。

```jpu warning
1 2 || 3 4
```

如果只是想分隔两个小节，使用一个 `|`。

## 文件头和字符串错误

文件头字段必须写在 `=` 分隔符之前，使用 `name: "value"` 语法，并让引号字符串保持在同一行。

```jpu invalid
title: "Open title
=
1 2 3 4
```

## 音符、和弦和时值错误

鼓音使用大写 `X`，和弦成员只能是音高音符，时值后缀要写在音符、休止符、鼓音或和弦之后。

```jpu invalid
{1 0 X}
```

```jpu invalid
1-/ 2 3 4
```

## 反复结尾错误

反复结尾组需要明确的最终结尾。非最终结尾用 `:|` 返回；最终结尾不写反复结束记号。

```jpu invalid
|: 1 2 3 4 | [1] 5 - 5 - :|
```

如果某条诊断看起来意外，可以先对照对应功能的语法页面，再运行 `pnpm run cli -- validate <file>` 检查完整源码。
