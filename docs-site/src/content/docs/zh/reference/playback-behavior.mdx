浏览器播放、MIDI、WAV 和 MP3 使用同一套编排和计时模型。本页说明记法解析后的可听结果；各 token 的写法请查阅语法页面。

## 从源码到声音

数字音阶从 C 大调开始：`1` 到 `7` 分别发出 MIDI 音高 `60`、`62`、`64`、`65`、`67`、`69` 和 `71`。乐谱调号会移动所有音级，每个八度标记会让音高变化 12 个半音。

显式变音记号会在该小节剩余部分改变对应音级。同一音级后续音符会继承它；状态会在下一条小节线重置。休止符会以静音占用时值。和弦的所有成员音会同时开始。有效的延音线会把后续时值合并到前一个发声音符，因此被延住的音符不会开始新的起音。

歌词、歌词对齐和歌词占位符只影响视觉效果；它们不会增加轨道，也不会改变播放、MIDI、WAV 或 MP3 时值。

使用 `$(...)` 或带计数的 `$$(...)` 语法编写的圆滑线也只影响视觉效果。它与延音线不同，不会合并时值、取消起音，也不会改变浏览器播放、MIDI、WAV 或 MP3 输出。

## 装饰音与延续

每一种装饰音都在主音的书写时值内完成：

- 上波音和下波音会在前半段形成主音-邻音-主音，再延续主音音高。
- 回音会在前半段形成四个等长音符，再延续主音。普通回音是上方-主音-下方-主音；逆回音顺序相反。
- 颤音会在完整时值中交替主音与上方音级邻音。`(tr)` 和 `(tr~)` 的发声相同；波浪延伸只用于记谱。
- 滑音在前四分之三保持源音高，在最后四分之一按等距半音移动。目标音符仍会有自己的正常起音。
- 前倚音和后倚音都会占用主音时值的四分之一。前倚音在缩短后的主音之前使用这段时间；后倚音在缩短后的主音之后使用它。多个倚音音高会平分这段倚音时间。

装饰音辅助音高遵循当前调号以及该音级在本小节中仍有效的变音记号。滑向相同发声音高会被忽略，并产生警告。

和弦装饰音使用两套不同的播放规则。对于波音、回音和颤音，解析调号、变音记号和八度标记后，只有实际发声音高最高的成员执行装饰音，其他成员持续发声且不会反复起音。倚音则修饰整个和弦的起音：倚音序列占用其书写时值的四分之一，因此所有成员共同使用缩短后的剩余时值。滑音仍要求源音和目标都是单个音高音符。

## 反复与导航

反复小节线和反复结尾会先展开，再解释导航标记。`[Segno]` 和 `[Coda]` 写在小节前；`[Fine]`、`[D.C.]`、`[D.S.]` 和 `[To Coda]` 写在小节后。

`[D.C.]` 会跳转一次到已展开书写时间线的开头。`[D.S.]` 会跳转一次到 `[Segno]`。跳转后，`[Fine]` 会停止播放或导出，`[To Coda]` 会跳转一次到 `[Coda]`。跳转后的路径既未遇到它们时，会继续到书写结尾。

未标记轨道的乐谱由唯一的谱面流控制导航。带标签编排中，导航遵循主 `T1` 时间线，也包括带标签模式中的隐式 `T1` 行。其他同时轨道上的导航标记仍会显示，但不控制播放，并产生警告。

## 轨道、Program 与力度

同一轨道组中的行会同时播放；下一组在前一组结束后开始。播放与导出会在最长编排轨道结束时完成。

旋律轨道的音色依次从 `Tn.program`、乐谱级 `program`、浏览器或 CLI 默认 Program 解析。`Pn.program` 为 P 轨道选择打击乐音色。`0..127` 是旋律 Program；`128..174` 选择鼓模式，其中 `X` 映射为打击乐音高 `program - 128 + 35`。

轨道音量依次从 `Tn.volume` 或 `Pn.volume`、乐谱级 `volume`、`1` 解析。它会与浏览器主音量或 CLI 音频振幅叠加。逐音符力度和力度线会先设置速度，再应用轨道和主音量缩放，因此相对平衡会保留。

## 开头静音

开启“忽略开头休止符”后，从头开始的播放以及 MIDI、WAV、MP3 导出会移除首条发声音轨之前的共享静音。其他轨道会保留在该公共裁剪后仍存在的休止符。此设置只改变开始时刻，不改变书写乐谱或轨道之间的关系。

点击渲染出的音符会从该音符开始浏览器播放。音符发声时，预览会高亮活跃音符，包括多轨中的同时音符。
