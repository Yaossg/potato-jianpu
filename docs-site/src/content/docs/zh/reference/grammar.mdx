## Token 列表

解析器会识别以下 token。空白和注释会在 token 之间被跳过。

| Token | 可接受源码 |
| --- | --- |
| `WS` | 空格或制表符 |
| `COMMENT` | `;` 后接直到换行前的文本 |
| `IDENTIFIER` | ASCII 字母开头，后接 ASCII 字母、数字或 `_` |
| `TEXT_KEY` | `title`、`subtitle` 或 `composer` |
| `KEY_SIGNATURE` | `C`、`F#` 或 `Bb` 这样的受支持调名 |
| `TIME_SIGNATURE` | `4/4`、`6/8` 或 `2/16` 这样的受支持分数 |
| `NUMBER` | 正的有限数字 |
| `BOOLEAN` | `true` 或 `false` |
| `PROGRAM_NUMBER` | 整数 `0` 到 `127` |
| `DEFAULT_PROGRAM_NUMBER` | 整数 `0` 到 `220` |
| `PROGRAM_NAME` | 带引号的旋律 General MIDI Program 名称 |
| `VOLUME_NUMBER` | `0` 到 `2` 的数字 |
| `TRACK_LABEL` | `T1` 到 `T9`，以及 `T11` 到 `T16` |
| `LYRIC_LABEL` | `L` 后接一个或多个数字 |
| `STRING` | 同一行内的双引号字符串 |
| `DIGIT` | `0` 到 `9` |
| `NOTE` | `1` 到 `7` |
| `REST` | `0` |
| `DRUM` | `X` |
| `BAR` | `\|` |
| `REPEAT_START` | `\|:` |
| `REPEAT_END` | `:\|` |
| `REPEAT_BOTH` | `:\|:` |
| `LBRACKET` | `[` |
| `RBRACKET` | `]` |
| `SHARPSHARP` | `##` |
| `SHARP` | `#` |
| `FLATFLAT` | `bb` |
| `FLAT` | `b` |
| `NATURAL` | `%` |
| `HALF` | `/` |
| `DOT` | `.` |
| `DASH` | `-` |
| `LOWER` | `,` |
| `HIGHER` | `'` |
| `TIE` | `~` |
| `EQUALS` | `=` |
| `NEWLINE` | `\n`、`\r\n` 或 `\r` |
| `EOF` | 文件结束 |
