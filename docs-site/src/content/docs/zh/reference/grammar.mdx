这一页是紧凑速查表。需要解释和示例时，请使用侧边栏中的语法指南页面。

| 构造 | 语法 |
| --- | --- |
| 文件头字段 | `name: value` |
| 分隔行 | `=` |
| 音符 | `1` 到 `7` |
| 休止符 | `0` |
| 鼓音 | `X` |
| 变音记号 | `#`、`##`、`b`、`bb`、`%` |
| 和弦 | `{1 3 5}` |
| 延音线 | `~1` |
| 小节线 | `|` |
| 反复开始 | `|:` |
| 反复结束 | `:|` |
| 反复结束并重新开始 | `:|:` |
| 反复结尾 | `[1]`、`[2]`、`[1,3]` |
| 轨道标签 | `T1:` 到 `T16:`，不包括 `T10:` |
| 歌词行 | `L1: "lyrics"` 或 `"lyrics"` |
| 注释 | `; comment` |

连续小节线会产生空小节警告，空小节会被忽略。

```jpu valid
title: "Repeat Example"
time: "4/4"
=
|: 1 2 3 4 | [1] 5 - 5 - :| [2] 1 - - -
```
