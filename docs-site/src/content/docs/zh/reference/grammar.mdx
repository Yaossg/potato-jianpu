## Token 列表

解析器会识别以下 token。空白和注释会在 token 之间被跳过。

| Token | 可接受源码 |
| --- | --- |
| `WS` | 空格或制表符 |
| `COMMENT` | `;` 后接直到换行前的文本 |
| `IDENTIFIER` | ASCII 字母开头，后接 ASCII 字母、数字或 `_` |
| `TEXT_KEY` | `title`、`subtitle` 或 `composer` |
| `KEY_SIGNATURE` | `C`、`F#` 或 `Bb` 这样的受支持调名 |
| `TIME_SIGNATURE` | `4/4`、`6/8` 或 `2/16` 这样的受支持分数 |
| `NUMBER` | 正的有限数字 |
| `BOOLEAN` | `true` 或 `false` |
| `PROGRAM_NUMBER` | 整数 `0` 到 `127` |
| `DEFAULT_PROGRAM_NUMBER` | 整数 `0` 到 `174` |
| `PERCUSSION_PROGRAM_NUMBER` | 整数 `128` 到 `174` |
| `PROGRAM_NAME` | 带引号的旋律 General MIDI Program 名称 |
| `VOLUME_NUMBER` | `0` 到 `2` 的数字，或 `0%` 到 `200%` 的百分数 |
| `MELODIC_TRACK_LABEL` | `T1` 到 `T9`，以及 `T11` 到 `T16` |
| `PERCUSSION_TRACK_LABEL` | `P` 后接一个或多个数字 |
| `LYRIC_LABEL` | `L` 后接一个或多个数字 |
| `STRING` | 同一行内的双引号字符串 |
| `AUTO_STRING` | `@` 后接同一行内的双引号歌词字符串 |
| `DIGIT` | `0` 到 `9` |
| `NOTE` | `1` 到 `7` |
| `REST` | `0` |
| `DRUM` | `X` |
| `BAR` | `\|` |
| `REPEAT_START` | `\|:` |
| `REPEAT_END` | `:\|` |
| `REPEAT_BOTH` | `:\|:` |
| `LBRACKET` | `[` |
| `RBRACKET` | `]` |
| `LPAREN` | `(` |
| `RPAREN` | `)` |
| `SHARPSHARP` | `##` |
| `SHARP` | `#` |
| `FLATFLAT` | `bb` |
| `FLAT` | `b` |
| `NATURAL` | `%` |
| `CARET` | `^` |
| `HALF` | `/` |
| `DOT` | `.` |
| `DASH` | `-` |
| `LOWER` | `,` |
| `HIGHER` | `'` |
| `TIE` | `~` |
| `VELOCITY` | `ppp`、`pp`、`p`、`mp`、`mf`、`f`、`ff` 或 `fff` |
| `CRESCENDO` | `<` |
| `DIMINUENDO` | `>` |
| `EQUALS` | `=` |
| `NEWLINE` | `\n`、`\r\n` 或 `\r` |
| `EOF` | 文件结束 |

在歌词 `STRING` 和 `AUTO_STRING` 内部，单独由空白分隔的 `_` 和 `~`
token 会作为歌词对齐占位符，而不是可见音节。`AUTO_STRING` 还会逐字切分
汉字，并把带连字符的 ASCII 单词切分成音节。
