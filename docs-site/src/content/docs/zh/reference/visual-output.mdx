当纸张、页边距、分页或导出格式改变后乐谱看起来不同，请查阅本页。这里说明浏览器预览、浏览器下载和 CLI 视觉导出的可见输出行为。

## 共享渲染模型

SVG、PNG 和 PDF 都从同一份乐谱布局开始生成；浏览器预览也使用该布局。因此页面宽度、纸张预设、方向、分页、页边距、记谱颜色、背景、页脚、页码和两端对齐会共同影响视觉输出。

文件头可以设置 `paginate`、`footer` 和 `numbering` 默认值。CLI 选项或浏览器当前的页面设置可以为本次导出选择不同结果，而无需修改 `.jpu` 源码。

## 页面尺寸与换行

`pageWidth` 同时是 SVG 视口宽度和一条视觉谱行可用的最大宽度。纸张预设会同时解析宽度和高度：A4 是 `1190 × 1684`、B5 是 `998 × 1418`、Letter 是 `1224 × 1584`（渲染器单位）。纵向和横向会交换预设尺寸；显式宽度或高度会在解析预设后覆盖对应尺寸。

页边距会相等地应用在四个方向。它会缩小文件头布局、乐谱换行、两端对齐和分页使用的内容框，但不会缩小导出的 SVG 或 PDF 页面本身。

渲染器只在小节之间换行，绝不会在小节内部断开。源码换行会保持为自然的视觉谱行边界。单个小节比内容框更宽时，它会独占一行并水平缩放以适配，而不会被拆开。较长的标签和对齐歌词可能需要更多水平空间；歌词不能在一条主声部视觉谱行上对齐时，会渲染为普通歌词行。

两端对齐只改变水平方向的视觉间距：

- 无：保留自然的小节间距。
- 除末行外：拉伸除最后一条外的每条视觉谱行。
- 所有行：拉伸每条视觉谱行。

它不会改变 `.jpu` 源码、播放时值、MIDI、WAV 或 MP3 输出。

## 分页与页脚元素

不开启分页时，视觉输出是一张自适应高度页面。开启分页后，渲染器会创建固定高度页面，只在第一页保留乐谱文件头，并绘制可见的页面边界。单独一行的 `---` 是手动分页：只有分页开启时，它才会让下一条乐谱行从新页开始。

页脚文本会绘制在每页左下角。页码会居中显示为 `当前 / 总页数`。二者都会预留垂直空间，因此乐谱内容不会与它们重叠。仅提供页面高度不会开启分页；请在浏览器中开启“分页”，或向 CLI 传入 `--paginate`。

## 各格式结果

| 格式 | 结果 | 分页与拆分 |
| --- | --- | --- |
| SVG | 确定性的矢量乐谱输出。下载的 SVG 会嵌入所需的装饰音字形。 | 默认的分页导出是一个合并 SVG。浏览器或 CLI 开启“拆分页”后会为每页生成一个 SVG。CLI 将 `-o` 值作为输出 stem，且不会覆盖已有目标文件。 |
| PNG | 使用内置导出字体和可配置像素倍率生成的、不透明的同一 SVG 布局栅格图像。 | 浏览器和 CLI 都支持在开启“拆分页”后按页生成 PNG。 |
| PDF | 嵌入 Unicode 文本和装饰音字体的矢量 PDF 页面。 | 每个渲染页都会成为一个 PDF 页；PDF 不会拆成多个独立下载。 |

浏览器下载使用当前页面设置和导出设置。CLI 将等价选择放在命令旁：`--paper`、`--orientation`、`--page-width`、`--page-height`、`--page-margin`、`--page-footer`、`--page-numbers`、`--paginate`、`--color` 和 `--background`。PNG 另外支持 `--png-scale`；SVG 和 PNG 支持 `--split-pages`。
