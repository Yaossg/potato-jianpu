当纸张、页边距、分页或导出格式改变后乐谱看起来不同，请查阅本页。这里说明浏览器预览、浏览器下载和 CLI 视觉导出的可见输出行为。

## 共享渲染模型

SVG、PNG 和 PDF 都从同一份乐谱布局开始生成；浏览器预览也使用该布局。因此页面宽度、纸张预设、方向、分页、页边距、记谱颜色、背景、页脚、页码、小节编号和两端对齐会共同影响视觉输出。

文件头可以设置 `paginate`、`footer`、`numbering` 和 `measureNumbers` 默认值。CLI 选项或浏览器当前的页面设置可以为本次导出选择不同结果，而无需修改 `.jpu` 源码。小节编号会用带括号的阿拉伯数字标注每条谱面行的首个书写小节，并跨页继续计数。

## 页面尺寸与源码行

`pageWidth` 同时是 SVG 视口宽度和一个渲染谱组可用的最大宽度。纸张预设会同时解析宽度和高度：A4 是 `1190 × 1684`、B5 是 `998 × 1418`、Letter 是 `1224 × 1584`（渲染器单位）。纵向和横向会交换预设尺寸；显式宽度或高度会在解析预设后覆盖对应尺寸。

页边距会相等地应用在四个方向。它会缩小文件头布局、乐谱缩放、两端对齐和分页使用的内容框，但不会缩小导出的 SVG 或 PDF 页面本身。

每条源码谱行始终对应一条渲染谱行；页面宽度不会在小节之间插入视觉换行。完整谱组比内容框更宽时，会通过水平缩放适配。同步多声部共享同一缩放比例；对齐歌词跟随该比例，保持音节与音符位置同步。普通歌词不继承乐谱缩放，只有它自身整行过宽时才独立水平缩放。水平缩放不会减小字体高度、垂直间距或行高。

两端对齐只改变水平方向的视觉间距：

- 无：保留自然的小节间距。
- 除末行外：拉伸除最后一条外的每条视觉谱行。
- 所有行：拉伸每条视觉谱行。

它不会改变 `.jpu` 源码、播放时值、MIDI、WAV 或 MP3 输出。

## 分页与页脚元素

不开启分页时，视觉输出是一张自适应高度页面。开启分页后，渲染器会创建固定高度页面，只在第一页保留乐谱文件头，并绘制可见的页面边界。同步多声部及其歌词会作为不可拆分的完整块一起移动。单块高于页面可用区域时，它会从新页顶部开始，不做纵向缩放，并产生布局警告。单独一行的 `---` 是手动分页：只有分页开启时，它才会让下一个谱组从新页开始。

页脚文本会绘制在每页左下角。页码会居中显示为 `当前 / 总页数`。二者都会预留垂直空间，因此乐谱内容不会与它们重叠。仅提供页面高度不会开启分页；请在浏览器中开启“分页”，或向 CLI 传入 `--paginate`。

## 各格式结果

| 格式 | 结果 | 分页与拆分 |
| --- | --- | --- |
| SVG | 带不透明页面背景的确定性矢量乐谱输出，默认背景为白色。下载的 SVG 会嵌入所需的装饰音字形。 | 默认的分页导出是一个合并 SVG。浏览器或 CLI 开启“拆分页”后会为每页生成一个 SVG。CLI 将 `-o` 值作为输出 stem，且不会覆盖已有目标文件。 |
| PNG | 使用内置导出字体和可配置像素倍率生成的、不透明的同一 SVG 布局栅格图像。 | 浏览器和 CLI 都支持在开启“拆分页”后按页生成 PNG。 |
| PDF | 嵌入 Unicode 文本和装饰音字体的矢量 PDF 页面。 | 每个渲染页都会成为一个 PDF 页；PDF 不会拆成多个独立下载。 |

浏览器下载使用当前页面设置和导出设置。CLI 将等价选择放在命令旁：`--paper`、`--orientation`、`--page-width`、`--page-height`、`--page-margin`、`--page-footer`、`--page-numbers`、`--paginate`、`--color` 和 `--background`。颜色和背景只接受 `#RRGGBB`。PNG 另外支持 `--png-scale`；SVG 和 PNG 支持 `--split-pages`。浏览器与 CLI 会对水平缩放、超高谱组、过小页面可用高度和异常页数报告相同类别的布局警告；只有这些警告时，CLI 视觉导出仍会成功。
