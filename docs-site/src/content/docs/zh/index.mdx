Modern Jianpu Markup 是用于简谱的文本格式和工具集。它包含浏览器编辑器、命令行界面、解析器、SVG 渲染器、播放功能，以及 SVG、PNG、MIDI、WAV、MP3 导出路径。

这份文档是编写 `.jpu` 乐谱的主要用户指南。可以先从一个短乐谱开始，再在语法页面里查找文件头、节奏、反复、歌词或多轨编排的具体规则。

## 可以编写什么

- `1` 到 `7` 的数字音符、休止符 `0`，以及鼓音 `X`。
- `title`、`composer`、`key`、`time`、`tempo` 等文件头字段。
- 变音记号、八度标记、和弦、延音线、歌词、反复小节线、反复结尾和多轨标签。
- 紧凑写法；乐谱主体里的空白不是独立语法模式。

```jpu valid
title: "Twinkle"
time: "4/4"
tempo: "96"
=
1 1 5 5 | 6 6 5 - |
4 4 3 3 | 2 2 1 -
```

## 怎样阅读

语法页面按照通常写谱的顺序组织：文件头、音符、节奏、反复、歌词和轨道。最后的语法参考是紧凑速查表，不是唯一记录规则的地方。

标记为 valid 的示例会用项目自身的解析器校验，避免参考文档和实现慢慢分叉。
