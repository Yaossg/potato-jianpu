Modern Jianpu Markup 是用于简谱的文本格式和工具集。它包含浏览器编辑器、命令行界面、解析器、SVG 渲染器、播放功能，以及 SVG、PNG、MIDI、WAV、MP3 导出路径。

这份文档是编写 `.jpu` 乐谱的主要用户指南。可以先从一个短乐谱开始，再在语法页面里查找文件头、节奏、反复、歌词或多轨编排的具体规则。

## 选择任务

- 写第一份乐谱：从下面的示例入手，然后在浏览器 App 中打开同一份源码。
- 修复警告或错误：从相关语法页面入手，或用 CLI 查看某个文件的诊断。
- 查找精确 token 或语法形状：知道要查哪一类格式之后，再使用 [语法参考](./reference/grammar/)。

## 第一份乐谱

先写一个小的 `.jpu` 文件。可选的文件头放在前面，然后是一行 `=`，最后是乐谱主体。

<JianpuSource
  title="第一句源码"
  source={`title: "First Phrase"
key: "C"
time: "4/4"
tempo: "88"
=
1 2 3 4 | 5 - 5 -`}
/>

需要即时预览、播放和下载时，使用浏览器 App。需要在终端里做可重复的校验或导出时，使用 CLI。

```sh
pnpm run cli -- validate examples/twinkle.jpu
pnpm run cli -- export-svg examples/twinkle.jpu -o twinkle.svg
pnpm run cli -- export-midi examples/twinkle.jpu -o twinkle.mid
```

这个仓库里的乐谱示例使用 `.jpu` 扩展名。

## 可以编写什么

- `1` 到 `7` 的数字音符、休止符 `0`，以及鼓音 `X`。
- `title`、`composer`、`key`、`time`、`tempo` 等文件头字段。
- 变音记号、八度标记、和弦、延音线、歌词、反复小节线、反复结尾和多轨标签。
- 紧凑写法；乐谱主体里的空白不是独立语法模式。

## 怎样阅读

语法页面按照通常写谱的顺序组织：文件头、音符、节奏、反复、歌词和轨道。最后的语法参考保留 token 列表和铁路图，方便精确查找；它不是唯一记录规则的地方。

标记为 valid 的示例会用项目自身的解析器校验，避免参考文档和实现慢慢分叉。
