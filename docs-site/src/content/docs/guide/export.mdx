## Visual exports

SVG is deterministic text output from the renderer. PNG rasterizes the same rendered SVG. PDF converts rendered SVG pages to vector PDF pages. All visual exports support page width, color, and background options.

```sh
pnpm run cli -- export-svg examples/twinkle.jpu -o twinkle.svg --page-width 1000 --color "#111827" --background "#ffffff"
pnpm run cli -- export-png examples/twinkle.jpu -o twinkle.png --page-width 1000 --color "#111827" --background "#ffffff"
pnpm run cli -- export-pdf examples/twinkle.jpu -o twinkle.pdf --page-width 1000 --color "#111827" --background "#ffffff"
```

## MIDI export

MIDI export writes a format 1 MIDI file with metadata, tempo, time signature, program handling, per-track volume, and one music track per labeled arrangement track.

The `--program` option is the fallback default Program. A score-level `program` header overrides that fallback, and `T1.program: 24` or `T2.program: "Violin"` override the score-level default for the matching labeled tracks.

Header fields such as `volume: 0.75` set the default MIDI note velocity scale. `T1.volume: 0.5` overrides that default for the matching track rather than multiplying by it. The resolved track volume is combined with the fixed default velocity.

```sh
pnpm run cli -- export-midi examples/twinkle.jpu -o twinkle.mid --program 0 --omit-initial-rest
```

## Audio exports

WAV and MP3 render through the TinySynth-based audio path. Browser exports use `OfflineAudioContext`; backend exports use the Node-capable offline render path. MP3 encoding is local through `lamejs`.

Audio exports use the same Program resolution as preview playback and MIDI export: per-track `Tn.program` values win, then score-level `program`, then the selected or CLI Program fallback. Resolved track volume comes from `Tn.volume`, then score-level `volume`, then `1`; it combines with the browser volume slider or CLI `--amplitude`, so master volume and track volume are applied together.

```sh
pnpm run cli -- export-wav examples/twinkle.jpu -o twinkle.wav --program 0 --sample-rate 44100 --amplitude 1 --omit-initial-rest
pnpm run cli -- export-mp3 examples/twinkle.jpu -o twinkle.mp3 --program 0 --sample-rate 44100 --amplitude 1 --bit-rate 128 --omit-initial-rest
```

Audio sample rate defaults to `44100`. MP3 bit rate defaults to `128` kbps.
