## Browser playback

The browser app uses WebAudioTinySynth. Playback schedules notes incrementally, highlights active rendered notes, and stops when the source changes.

Click-to-play starts from rendered note metadata. If the clicked note is the first playback note and initial-rest omission is enabled, leading rests are skipped.

Rendered score previews in the documentation use the same playback compiler. When a preview includes playback controls, clicking a rendered note starts that preview from the clicked note.

## Programs and drums

Programs `0..127` use melodic TinySynth programs. Programs `128..220` use drum mode. In drum mode, source `X` maps to percussion note `program - 128 + 35`.

Use `program` in the file header to set the score-level default Program. Use `Tn.program` to assign a melodic Program to a labeled track; it overrides `program` for that track. Per-track numeric values are limited to `0..127`, and quoted names resolve through the same General MIDI Program list used by the browser selector. The browser Program selector remains the fallback only when the score omits `program`.

Use `volume` to set the score-level default track volume, and `Tn.volume` to override one track from `0` to `2` or `0%` to `200%`. The resolved track volume multiplies with the browser volume slider, so a quiet track stays quiet when the master volume changes.

The browser app includes default Program selection, volume, audition, and an initial-rest omission toggle in Sound Settings.

## Repeats and tracks

Repeat barlines and repeated endings are expanded for playback and export. Labeled tracks play together inside a voice group; the next group starts after the previous group ends.

Lyrics render visually but do not affect playback timing.
