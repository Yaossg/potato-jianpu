Modern Jianpu Markup is a text format and toolkit for Jianpu scores. It includes a browser editor, a command-line interface, a parser, an SVG renderer, playback, and export paths for SVG, PNG, MIDI, WAV, and MP3.

This documentation is the primary user-facing guide for writing `.jpu` scores. Start with a short score, then use the syntax pages when you need a precise rule for metadata, rhythm, repeats, lyrics, or multi-track arrangements.

## Choose a task

- Write a first score: start with [Getting Started](./getting-started/), then open the same source in the browser app.
- Fix a warning or error: use [Troubleshooting](./guide/troubleshooting/) to match the diagnostic to the relevant syntax page.
- Look up a precise token: use the compact [Grammar Reference](./reference/grammar/) after you know which part of the format you need.

## What you can write

- Numbered notes `1` through `7`, rests `0`, and drum notes `X`.
- File metadata such as `title`, `composer`, `key`, `time`, and `tempo`.
- Accidentals, octave marks, chords, ties, lyrics, repeat barlines, repeated endings, and labeled tracks.
- Compact notation where whitespace is optional between score tokens.

## How to read the docs

The syntax pages explain the format in the same order a score is usually written: file header, notes, rhythm, repeats, lyrics, and tracks. The grammar reference at the end is a compact lookup table, not the only place where the rules are documented.

Examples marked as valid are checked against the project parser so the guide stays aligned with the implementation.
