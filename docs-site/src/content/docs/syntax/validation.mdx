Diagnostics are documented with the syntax that causes them. Use this page only as a compact index when an older link or search result lands here.

| Diagnostic area | Where to look |
| --- | --- |
| Header fields, strings, `key`, `time`, `tempo` | [File Header](../header/) |
| Notes, drums, accidentals, octaves, chords, empty chords, ties | [Notes and Rests](../notes/) |
| Duration suffixes and measure-duration warnings | [Rhythm](../rhythm/) |
| Repeat barlines and repeated endings | [Repeats](../repeats/) |
| Lyric counts, lyric placement, track labels, track grouping | [Lyrics and Tracks](../lyrics-tracks/) |

The CLI remains the best way to inspect the full diagnostic list for a file:

```sh
pnpm run cli -- validate path/to/score.jpu
```
