## Slash and Dot Durations

Slashes shorten a note. One slash halves the duration, and additional slashes keep dividing it.

<JianpuSource
  title="Slash duration source"
  source={`time: 4/4
=
1/ 2/ 3 4 5`}
/>

<ScorePreview
  title="Slash durations"
  source={`time: 4/4
=
1/ 2/ 3 4 5`}
/>

Dots lengthen a note by adding half of the previous duration value.

<JianpuSource
  title="Dotted duration source"
  source={`time: 6/8
=
1. 2/ 3/ 4/`}
/>

<ScorePreview
  title="Dotted duration"
  source={`time: 6/8
=
1. 2/ 3/ 4/`}
/>

Dash duration marks and slash duration marks are separate duration forms. Do not combine them on the same note.

## Duration Table

| Syntax | Duration |
| --- | --- |
| `1` | quarter note |
| `1-` | half note |
| `1--` | dotted half note |
| `1---` | whole note |
| `1/` | eighth note |
| `1//` | sixteenth note |
| `1///` | thirty-second note |
| `1.` | dotted quarter note |
| `1..` | double-dotted quarter note |
| `1/.` | dotted eighth note |

Duration marks belong to the note, rest, drum note, or chord immediately before them. A stray duration mark without a preceding item is invalid.
