Plain notes divide the current measure into regular quarter-note units in common time.

```jpu valid
time: "4/4"
=
1 2 3 4
```

A dash extends the previous note or rest.

```jpu valid
time: "4/4"
=
1 - 2 -
```

Slashes shorten a note. One slash halves the duration, and additional slashes keep dividing it.

```jpu valid
time: "4/4"
=
1/ 2/ 3 4 5
```

Dots lengthen a note by adding half of the previous duration value.

```jpu valid
time: "6/8"
=
1. 2/ 3/ 4/
```

Dash duration marks and slash duration marks are separate duration forms. Do not combine them on the same note.

| Syntax | Duration |
| --- | --- |
| `1` | quarter note |
| `1-` | half note |
| `1--` | dotted half note |
| `1---` | whole note |
| `1/` | eighth note |
| `1//` | sixteenth note |
| `1///` | thirty-second note |
| `1.` | dotted quarter note |
| `1..` | double-dotted quarter note |
| `1/.` | dotted eighth note |

Duration marks belong to the note, rest, drum note, or chord immediately before them. A stray duration mark without a preceding item is invalid.

```jpu valid
time: "4/4"
=
{1 3 5} - 0/ 1.
```

<JianpuExample title="Mixed duration forms" status="invalid" description="Dash extensions and slash/dot suffixes cannot be combined on the same item.">

```jpu invalid
1-/ 2 3 4
```

</JianpuExample>

<JianpuExample title="Stray duration mark" status="invalid" description="A duration suffix must follow a note, rest, drum note, or chord.">

```jpu invalid
/1 2 3 4
```

</JianpuExample>

Measure-duration warnings use the active `time` header. A warning means the document can still render, but the measure is rhythmically longer or shorter than the declared meter.

<JianpuExample title="Short measure" status="warning" description="In 4/4, this measure is shorter than the declared meter.">

```jpu warning
time: "4/4"
=
1 2
```

</JianpuExample>
