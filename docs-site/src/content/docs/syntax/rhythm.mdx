## Slash and Dot Durations

Slashes shorten a note. One slash halves the duration, and additional slashes keep dividing it.

<JianpuSource
  title="Slash duration source"
  source={`time: 4/4
===
1/ 2/ 3 4 5`}
/>

<ScorePreview
  title="Slash durations"
  source={`time: 4/4
===
1/ 2/ 3 4 5`}
/>

Dots lengthen a note by adding half of the previous duration value.

<JianpuSource
  title="Dotted duration source"
  source={`time: 6/8
===
1. 2/ 3/ 4/`}
/>

<ScorePreview
  title="Dotted duration"
  source={`time: 6/8
===
1. 2/ 3/ 4/`}
/>

Dash duration marks and slash duration marks are separate duration forms. Do not combine them on the same note.

## Duration Table

| Syntax | Duration |
| --- | --- |
| `1` | quarter note |
| `1-` | half note |
| `1--` | dotted half note |
| `1---` | whole note |
| `1/` | eighth note |
| `1//` | sixteenth note |
| `1///` | thirty-second note |
| `1.` | dotted quarter note |
| `1..` | double-dotted quarter note |
| `1/.` | dotted eighth note |

Duration marks belong to the note, rest, drum note, or chord immediately before them. A stray duration mark without a preceding item is invalid.

## Ties

A leading tie marker `~` ties a note to the previous compatible note, combining their playback and export duration.

<JianpuSource
  title="Tie source"
  source={`1 - - - | ~1 - - -`}
/>

<ScorePreview title="Rendered tie" source={`1 - - - | ~1 - - -`} />

The tie target must be compatible with the previous sounding pitch. A tied note cannot be the first note in a track, and ties are validated independently for labeled tracks.

<JianpuSource
  title="Compatible tie source"
  source={`time: 2/4
===
#4 ~4 | X ~X | {1 3 5} ~{1 3 5}`}
/>

<ScorePreview
  source={`time: 2/4
===
#4 ~4 | X ~X | {1 3 5} ~{1 3 5}`}
/>

<JianpuExample
  title="Illegal tie"
  status="invalid"
  description="A tie cannot start a track, follow a rest, or change pitch target."
  source={`1 0 ~1`}
/>

## Slurs

Use the contiguous opening marker `$(` and a closing `)` to draw a slur over two or more pitch notes or chords. Slurs may cross barlines, source lines, visual wrapping, and page breaks, and they may be nested.

<JianpuSource
  title="Slur source"
  source={`time: 4/4
===
$(1(^) 2 {3 5} 4)`}
/>

<ScorePreview
  title="Rendered slur"
  source={`time: 4/4
===
$(1(^) 2 {3 5} 4)`}
/>

Use the contiguous `$$(` opener to add a number at the center of the horizontal slur section. The number counts all pitch notes and chords in the slur, including both endpoints. A chord counts as one, and an interior rest is not counted. Ordinary `$(...)` slurs have no number.

<JianpuSource
  title="Counted slur source"
  source={`time: 4/4
===
$$(1 {2 4} 3 4)`}
/>

<ScorePreview
  title="Rendered counted slur"
  source={`time: 4/4
===
$$(1 {2 4} 3 4)`}
/>

The slur endpoints must be pitch notes or chords. A rest may occur inside a slur, but it produces a warning while the slur still renders. Drum notes are not accepted inside slurs. The first pitch note or chord must follow `$(` or `$$(` on the same source line.

<JianpuSource
  title="Nested and cross-line slurs"
  source={`time: 2/4
===
$($(1 2)
3 4)`}
/>

A slur adds a short legato overlap between adjacent different pitches in browser playback and MIDI, WAV, or MP3 output, without moving their written onset times. Rests break that connection, and repeated pitches remain separately attacked. A tie uses `~`, connects compatible repeated pitches, and combines their sounding duration. Both may appear together, with the shorter tie drawn closer to the notes.

<JianpuExample
  title="Slur containing a rest"
  status="warning"
  description="The arc still renders, but a rest inside a slur produces a warning."
  source={`time: 3/4
===
$(1 0 2)`}
/>

<JianpuExample
  title="Drum note inside a slur"
  status="invalid"
  description="Slurs accept pitch notes and chords, with optional interior rests, but not drum notes."
  source={`$(1 X 2)`}
/>
