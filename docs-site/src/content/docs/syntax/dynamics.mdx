## Dynamic Markings

Per-note dynamics use Italian dynamic markings as a prefix before the note. A dynamic applies to exactly one note. Spaces between the marking and the note are optional.

<JianpuSource
  title="Dynamic marking source"
  source={`time: 2/4
===
f1 p2 | mf3 ff4`}
/>

<ScorePreview title="Rendered dynamics" source={`time: 2/4
===
f1 p2 | mf3 ff4`} />

Eight dynamic levels are supported, each mapped to a MIDI velocity value:

| Marking | Meaning | MIDI velocity |
| --- | --- | --- |
| `ppp` | pianississimo | 16 |
| `pp` | pianissimo | 33 |
| `p` | piano | 49 |
| `mp` | mezzo-piano | 61 |
| `mf` | mezzo-forte | 73 |
| `f` | forte | 85 |
| `ff` | fortissimo | 102 |
| `fff` | fortississimo | 118 |

Dynamics can also be applied to chords, rests, and tied notes.

<JianpuSource
  title="Dynamics with chords, rests, and ties"
  source={`time: 2/4
===
mf {1 3 5} - | f1 ~f1 | p0 -`}
/>

<ScorePreview
  source={`time: 2/4
===
mf {1 3 5} - | f1 ~f1 | p0 -`}
/>

## Hairpins

Gradual dynamics use paired hairpin markers before durable notes. Write `<` at both endpoints for crescendo and `>` at both endpoints for diminuendo. The first marker starts the hairpin, and the matching marker later in the same track ends it.

<JianpuSource
  title="Hairpin dynamic source"
  source={`time: 2/4
===
p < 1 2
3 f < 4`}
/>

<ScorePreview
  title="Rendered hairpin dynamics"
  source={`time: 2/4
===
p < 1 2
3 f < 4`}
/>

Opposite hairpins can meet on one note: `<>` ends a crescendo and starts a diminuendo on that note, while `><` does the reverse. Hairpins may cross source lines and visual wraps; the renderer draws a separate hairpin segment on each visual line.

## Diagnostics

If both endpoints have explicit dynamics, the parser warns when the hairpin direction disagrees with the written dynamics.

<JianpuExample
  title="Hairpin direction warning"
  status="warning"
  description="A crescendo should end louder than it starts."
  source={`time: 3/4
===
f < 1 2 p < 3`}
/>

<JianpuExample
  title="Tie before dynamic"
  status="invalid"
  description="The dynamic marker must come after the tie prefix: write ~f1, not f~1."
  source={`1 f~1`}
/>

When no per-note dynamic or hairpin endpoint is written, the track-level or score-level volume from the header controls the velocity.
