## Header Basics

The file header is line-oriented. Put it before the `=` separator.

<JianpuSource
  title="Header source"
  source={`title: "Evening Song"

key: "G"
time: "3/4"
tempo: "72"
=
5 6 5 | 3 - -`}

## Fields

Known fields include:

| Field | Meaning |
| --- | --- |
| `title` | Main title rendered above the score. |
| `subtitle` | Secondary title text. |
| `composer` | Composer or source text. |
| `key` | Key signature for playback and export. |
| `time` | Time signature used for measure-duration validation. |
| `tempo` | Playback and MIDI tempo. |
| `hidden` | Any non-empty value hides the rendered header block. |

Unknown fields are preserved as metadata. They do not change parsing, rendering, playback, or export behavior unless a future version gives them meaning.

## Strings and Validation

Header values use quoted strings. Escape sequences are kept as source text, so write the visible metadata exactly as you want users to read it.

<JianpuSource
  title="Quoted header source"
  source={`title: "Evening Song"
composer: "Anonymous"
tempo: "72"
=
1 2 3 4`}
/>

<ScorePreview
  title="Rendered quoted header"
  source={`title: "Evening Song"
composer: "Anonymous"
tempo: "72"
=
1 2 3 4`}
/>

Header names must start with a letter and may continue with letters, digits, or underscores. A header string must close on the same line.

<JianpuExample
  title="Unterminated header string"
  status="invalid"
  description="The title string never closes, so the document is invalid."
  source={`title: "Open title
=
1 2 3 4`}
/>

The `key` field accepts `C`, `C#`, `Db`, `D`, `D#`, `Eb`, `E`, `F`, `F#`, `Gb`, `G`, `G#`, `Ab`, `A`, `A#`, `Bb`, and `B`. One space inside the value is ignored, and accidental-first spellings such as `#F` or `bB` are accepted. It affects playback and export pitch spelling; invalid key names are reported as diagnostics.

## Musical Defaults

The `time` field uses `beats/beat-unit`, such as `4/4`, `3/4`, or `6/8`. Allowed numerators are `2`, `3`, `4`, `6`, `9`, and `12`; allowed denominators are `2`, `4`, `8`, and `16`. It is used for measure-duration validation. Measures that do not add up to the time signature produce warnings, not hard parse failures.

The `tempo` field is a positive beats-per-minute value. Integer and decimal values such as `96`, `120`, and `132.5` are accepted. It is used by playback, MIDI export, and audio export.

## Hidden Header

Use `hidden` to keep the rendered header block out of the SVG while retaining the metadata in the document. Any non-empty string enables this behavior.

<JianpuSource
  title="Hidden header source"
  source={`title: "Practice Line"
composer: "Anonymous"
hidden: "composer"
=
1 2 3 4`}
/>

<ScorePreview
  title="Rendered without header block"
  source={`title: "Practice Line"
composer: "Anonymous"

1 2 3 4`}
/>

## Track and Lyric Labels

Track and lyric labels can also be named in the file header. Use the same label text that appears in the score body.
