## Header Basics

The file header is line-oriented metadata placed before the `===` separator line. Without that separator, the whole file is parsed as score text.

<JianpuSource
  title="Header source"
  source={`title: "Evening Song"
subtitle: "Short Study"
composer: "Anonymous"
key: G
time: 3/4
tempo: 72
===
5 6 5 | 3 - -`}
/>

## Field Summary

Known fields include:

| Category | Fields | Meaning |
| --- | --- | --- |
| Score display | `title`, `subtitle`, `composer`, `hidden`, `paginate`, `numbering`, `measureNumbers`, `footer` | Visible metadata, header visibility, paginated visual rendering, page numbers, measure numbers, and page footer text. |
| Musical defaults | `key`, `time`, `tempo` | Pitch spelling, measure-duration validation, and playback/export tempo. |
| Playback defaults | `program`, `volume` | Score-level Program and track volume defaults for playback and export. |
| Track and lyric labels | `Tn.name`, `Tn`, `Pn.name`, `Pn`, `Ln.name`, `Ln` | Visible names for melodic tracks, percussion tracks, and lyric lines. |
| Track playback overrides | `Tn.program`, `Pn.program`, `Tn.volume`, `Pn.volume` | Per-track Program and volume overrides for playback and export. |

Default values are empty for `title`, `subtitle`, `composer`, and `footer`; `hidden`, `numbering`, `measureNumbers`, and `paginate` default to `false`; `key` defaults to `C`; `time` defaults to `4/4`; `tempo` defaults to `120`; `program` falls back to the browser or CLI Program setting; and `volume` defaults to `1`.

Only documented header fields are accepted. Unknown fields such as `arranger` or misspelled fields such as `temop` are parse errors.

## Syntax and Validation

Header field names are case-sensitive. Text values and visible label names must be quoted; `key`, `time`, `tempo`, `hidden`, `numbering`, `measureNumbers`, and `paginate` use unquoted typed values.

Text fields use double-quoted strings and must stay on one line. A backslash skips the following character during tokenization, but the backslash is preserved as source text rather than interpreted as an escape sequence. Write visible metadata exactly as you want users to read it.

## Score Display

Use `title`, `subtitle`, and `composer` for text rendered above the score. These fields do not affect parsing, playback timing, or export format choices.

Use `hidden: true` to keep the rendered header block out of the SVG while retaining the metadata in the document. Use `hidden: false`, or omit the field, to render the header normally.

<JianpuSource
  title="Hidden header source"
  source={`title: "Practice Line"
composer: "Anonymous"
hidden: true
===
1 2 3 4`}
/>

<ScorePreview
  title="Rendered without header block"
  source={`title: "Practice Line"
composer: "Anonymous"
hidden: true
===
1 2 3 4`}
/>

Use `paginate: true` to render fixed-height pages by default for SVG, PNG, and PDF output. Use `footer` to set footer text rendered at the bottom-left of each page. Use `numbering: true` to render centered page numbers as `current / total`. Browser and CLI render options can still override these fields for a specific export.

Use `measureNumbers: true` to label the first measure of every written score line above its left boundary. Labels use parenthesized Arabic numbers such as `(1)` and `(5)`, continue across pages, and count written measures without expanding repeats. A simultaneous multi-track group receives one label based on its primary line. The browser's **Measure numbers** setting can enable or disable these labels without editing the source.

<JianpuSource
  title="Page adornment header source"
  source={`paginate: true
footer: "modern-jianpu"
numbering: true
measureNumbers: true
===
1 2 3 4
---
5 6 7 1'`}
/>

## Musical Defaults

The `key` field accepts `C`, `C#`, `Db`, `D`, `D#`, `Eb`, `E`, `F`, `F#`, `Gb`, `G`, `G#`, `Ab`, `A`, `A#`, `Bb`, and `B`. Accidental-first spellings such as `#F` or `bB` are accepted. It affects playback and export pitch spelling; invalid key names are diagnostics.

The `time` field uses `beats/beat-unit`, such as `4/4`, `3/4`, or `6/8`. Allowed numerators are `2`, `3`, `4`, `6`, `9`, and `12`; allowed denominators are `2`, `4`, `8`, and `16`. Measures that do not add up to the time signature produce warnings, not hard parse failures.

The `tempo` field is a positive beats-per-minute value. Integer and decimal values such as `96`, `120`, and `132.5` are accepted. It is used by playback, MIDI export, and audio export.

The `program` field sets the score-level default Program for playback and export. Numeric values can be `0` through `174`; values `128..174` enable drum mode. Quoted melodic Program names are also accepted. The browser and CLI Program controls are used only when the file header omits `program`.

The `volume` field sets the score-level default track volume. Values are numbers from `0` to `2`, or percentages from `0%` to `200%`; `1` and `100%` are neutral. It is a default for tracks that do not have per-track volume overrides.

## Track and Lyric Labels

Header fields can name melodic tracks, percussion tracks, and lyric lines. Use `Tn.name` or shorthand `Tn` for melodic track names, `Pn.name` or shorthand `Pn` for percussion track names, and `Ln.name` or shorthand `Ln` for lyric labels.

For a score with one unlabeled music line, `T1.name` still names that rendered line. Track grouping and lyric attachment rules live in the Lyrics and Tracks page.

<JianpuSource
  title="Track and lyric label source"
  source={`T1.name: "Melody"
T2: "Harmony"
P1.name: "Drums"
L1.name: "Verse"
===
T1: 1 2 3 4
T2: 5 5 5 5
P1: X 0 X 0
L1: "do re mi fa"`}

## Track Playback Defaults

Use `Tn.program` to assign a melodic General MIDI Program to a melodic arrangement track. Values can be an integer from `0` to `127`, or a quoted Program name from the browser Program selector. Quoted names are matched case-insensitively after trimming surrounding whitespace.

Use `Pn.program` to assign a Percussion Program (`128`–`174`) to a P-labeled percussion track. P-track programs default to `128` when omitted. `T10.program` is not accepted because T10 is the reserved MIDI drum channel.

Use `Tn.volume` or `Pn.volume` to set one playback/export track volume. Values are numbers from `0` to `2`, or percentages from `0%` to `200%`; `1` and `100%` are neutral. Per-track volume overrides the score-level `volume` default for that track instead of multiplying by it.

For a score with one unlabeled music line, `T1.program` and `T1.volume` apply to that single playback/export track.
