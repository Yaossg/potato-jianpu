## Header Basics

The file header is line-oriented. Put it before the `=` separator.

## Fields

Known fields include:

| Field | Meaning |
| --- | --- |
| `title` | Main title rendered above the score. |
| `subtitle` | Secondary title text. |
| `composer` | Composer or source text. |
| `key` | Key signature for playback and export. |
| `time` | Time signature used for measure-duration validation. |
| `tempo` | Playback and MIDI tempo. |
| `hidden` | Boolean flag that hides the rendered header block. |
| `program` | Score-level default Program for playback and export. |
| `volume` | Score-level default track volume for playback and export. |
| `Tn.program` | Per-track playback and export Program override for melodic tracks. |
| `Tn.volume` | Per-track playback and export volume multiplier. |

Default values are empty for `title`, `subtitle`, and `composer`; `hidden` defaults to `false`, `key` defaults to `C`, `time` defaults to `4/4`, `tempo` defaults to `120`, `program` falls back to the browser or CLI Program setting, and `volume` defaults to `1`.

Only documented header fields are accepted. Unknown fields such as `arranger` or misspelled fields such as `temop` are parse errors.

## Strings and Validation

Text fields use double-quoted strings and must stay on one line. A backslash skips the following character during tokenization, but the backslash is preserved as source text rather than interpreted as an escape sequence. Write the visible metadata exactly as you want users to read it.

<JianpuSource
  title="Quoted header source"
  source={`title: "Evening Song"
composer: "Anonymous"
tempo: 72
=
1 2 3 4`}
/>

<ScorePreview
  title="Rendered quoted header"
  source={`title: "Evening Song"
composer: "Anonymous"
tempo: 72
=
1 2 3 4`}
/>

Header names are case-sensitive. Text values and visible label names must be quoted; `key`, `time`, `tempo`, and `hidden` use unquoted typed values. A header string must close on the same line.

<JianpuExample
  title="Unterminated header string"
  status="invalid"
  description="The title string never closes, so the document is invalid."
  source={`title: "Open title
=
1 2 3 4`}
/>

The `key` field accepts `C`, `C#`, `Db`, `D`, `D#`, `Eb`, `E`, `F`, `F#`, `Gb`, `G`, `G#`, `Ab`, `A`, `A#`, `Bb`, and `B`. Accidental-first spellings such as `#F` or `bB` are accepted. It affects playback and export pitch spelling; invalid key names are reported as diagnostics.

## Musical Defaults

The `time` field uses `beats/beat-unit`, such as `4/4`, `3/4`, or `6/8`. Allowed numerators are `2`, `3`, `4`, `6`, `9`, and `12`; allowed denominators are `2`, `4`, `8`, and `16`. It is used for measure-duration validation. Measures that do not add up to the time signature produce warnings, not hard parse failures.

The `tempo` field is a positive beats-per-minute value. Integer and decimal values such as `96`, `120`, and `132.5` are accepted. It is used by playback, MIDI export, and audio export.

The `program` field sets the score-level default Program for playback and export. Numeric values can be `0` through `220`; values `128..220` enable the same drum mode used by the browser and CLI Program controls. Quoted melodic Program names are also accepted. The browser and CLI Program controls are used only when the file header omits `program`.

The `volume` field sets the score-level default track volume. Values are numbers from `0` to `2`, or percentages from `0%` to `200%`; `1` and `100%` are neutral. It is a default for tracks that do not have `Tn.volume`, not a multiplier stacked on top of `Tn.volume`.

## Hidden Header

Use `hidden: true` to keep the rendered header block out of the SVG while retaining the metadata in the document. Use `hidden: false`, or omit the field, to render the header normally.

=

## Track and Lyric Labels

Track and lyric labels can also be named in the file header. Use `Tn.name` or shorthand `Tn` for track names, and `Ln.name` or shorthand `Ln` for lyric labels.

For a score with one unlabeled music line, `T1.name` still names that rendered line.

<JianpuSource
  title="Track and lyric label source"
  source={`T1.name: "Melody"
T2: "Harmony"
L1.name: "Verse"
=
T1: 1 2 3 4
T2: 5 5 5 5
L1: "do re mi fa"`}
/>

## Track Programs

Use `Tn.program` in the file header to assign a melodic General MIDI Program to a labeled arrangement track. Values can be an integer from `0` to `127`, or a quoted Program name from the browser Program selector. Quoted names are matched case-insensitively after trimming surrounding whitespace.

`Tn.program` overrides the score-level `program` default for that track. The browser and CLI Program controls act as the default only when the file header omits `program`. For a score with one unlabeled music line, `T1.program` applies to that single playback/export track. `T10.program` and drum Program values are reserved for a later drum-track design.

<JianpuSource
  title="Track Program source"
  source={`program: 24
T1.name: "Melody"
T1.program: 0
T2.name: "Violin"
T2.program: "Violin"
=
T1: 1 2 3 4
T2: 5, 6, 7, 1`}
/>

## Track Volumes

Use `Tn.volume` in the file header to set one playback/export track volume. Values are numbers from `0` to `2`, or percentages from `0%` to `200%`; `1` and `100%` are neutral, `0.5` and `50%` are half volume, `0` and `0%` mute the track, and `2` and `200%` double the track velocity/gain before clamping.

`Tn.volume` overrides the score-level `volume` default for that track instead of multiplying by it. The resolved track volume combines with the browser volume slider or CLI audio `--amplitude`; it does not replace the master volume. For MIDI export, the resolved track volume scales that track's note velocity. For browser playback, WAV, and MP3, the master volume/amplitude and resolved per-track volume are both applied.

For a score with one unlabeled music line, `T1.volume` applies to that single playback/export track.
